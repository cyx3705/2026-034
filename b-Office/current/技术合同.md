# HistoryStrenua 技术合同

本文件合并当前有效的需求与架构。关键决策单独保存在 `有效决策.md`；已失效内容移入
`../history/`，不得继续作为实现依据。

## 现行需求

### REQ-001 快捷指令登记表

- 目的：PowerSW 会持续加快捷指令，加一条不应改页面描述、动作声明和指令注册三处。
- 要求：每条快捷指令是一条 `QuickCommand`（键、指令名、标题、摘要、用法、执行体），登记在
  `QuickCommands.All`。控制面板按钮（1.7.0，按命令类分面板）、类选项（命令类 → 类名，`QuickCommands.ClassTitle`，
  `hole` → 「孔」、`drawing` → 「出图」（1.9.0）、`check` → 「检查」）、动作声明（`strenua.quick.<键>`）、总线指令全部由登记表生成。目前都不带参数；将来带参数时在
  `QuickCommand` 上加参数表，由页面生成器渲染成输入控件并经动作占位符传入，已有无参指令不受影响。
- 验收：离线用例「buttons, actions and commands line up」「class panels: buttons and switches」「list rows」。
- 关联组件：`b-Code/HistoryStrenua/QuickCommand.cs`、`StrenuaPage.cs`、`HistoryStrenuaModule.cs`
- 关联验证：`VERIFY-UNIT`

### REQ-002 附着而不接管

- 目的：PowerSW 作用于用户手上的 SolidWorks，任何「顺手」的接管都会打断用户。
- 要求：只经运行对象表附着已运行的 SolidWorks（`GetActiveObject`），没开就失败并说明；
  不改 `Visible` / `UserControl`、不 `ExitApp`；收工只释放本次经手的 COM 引用。
  一次只跑一条快捷指令（它们共用同一个选择集），第二条直接回执「还在执行」。可取消。
- 验收：VERIFY-LIVE 第 1、5 步。
- 关联组件：`b-Code/HistoryStrenua/SolidWorks/`、`QuickCommandRunner.cs`
- 关联验证：`VERIFY-LIVE`

### REQ-003 孔标注

- 目的：给工程图视图里的孔逐个加孔标注是纯重复劳动。
- 要求：
  1. 活动文档必须是工程图。当前选择里有视图（或视图里的任何对象）就用它；否则等用户点选，最多 60 秒。
  2. 孔的判据是几何：整圈圆边（无端点）、旁边有一张**内凹**且同半径的圆柱面、轴线正对图纸
     （视图空间里与法向夹角余弦 ≥ 0.999）。内凹 = 面法向指向轴线：在圆上取点求曲面法向，
     再按 `FaceInSurfaceSense`（**true 表示面法向与曲面法向相反**，见 DEC-005）换算成面法向。异形孔向导的各类孔与手工切出的圆孔都算；
     开口槽口端部半圆、凸台外圆、侧视投影不算。腰型孔见 REQ-007。
  3. 装配视图逐个可见组件取边，几何先乘组件变换再乘视图的模型→图纸变换。
  4. 图纸上圆心相距不到 0.02 mm 的圆边算同一个孔（沉头与底孔、通孔上下口），取半径最小的那条。
  5. **每种孔只标一次**：一种 = 同一组件、同一特征（孔壁所属特征）、同一孔径。SolidWorks 的孔标注会自己写上
     「N×」，每个都标就是同一行字重复 N 遍。标在这一种里最靠左上的孔上。
  6. 一种孔里只要有一个已有孔标注，整种跳过。新标注放在孔的**左上方**（1.1.0 起，DEC-008）：引线折点（文字下划线右端）
     在孔心左上 45°、离孔心「孔半径 + 12 mm」，文字从折点往左排，引线斜向右下指到孔。文字多宽生成后才知道，
     所以先落位、再读显示数据里最长的水平线（下划线）的右端，平移整个标注对准，最多挪三次、偏差 0.1 mm 内。
  7. 回执说明认出几个孔共几种、新加几个、跳过几种、SolidWorks 拒绝几个；确有要加的却一个都没加上时回执失败。
- 验收：离线用例覆盖合并、分种、跳过、排序、放置（左上）、下划线右端识别、正对判定、孔壁判定；真机见 VERIFY-LIVE。
- 关联组件：`b-Code/HistoryStrenua/HoleCallout.cs`、`HoleCalloutPlanner.cs`
- 关联验证：`VERIFY-UNIT`、`VERIFY-LIVE`

### REQ-005 中心符号线（1.1.0）

- 目的：给视图里的孔一个个插中心符号线、再连成组是纯重复劳动；旧的单个中心符号线也要一个个删。
- 要求：
  1. 取视图、认孔、同心合并、分种与 REQ-003 第 1–5 条完全相同（共用 `HoleScan` 与 `HoleCalloutPlanner`）。
  2. **重新标记**：先删掉标着这些孔的旧中心符号线——孔心取它附着的圆边，附着丢失时取它自己记的位置过视图变换；
     一组里只要有一个孔心落在孔上整组删。不在孔上的中心符号线（圆角、开口槽口）不动。删完回读，最多删三遍
     （真机上第一遍偶有漏删）；仍有删不掉的就失败、不重标。
  3. 每种孔一组：两个孔以上用 `InsertCenterMark3(swCenterMark_LinearGroup)`，再把 `ConnectionLines` 设为
     `swCenterMark_ShowLinearConnectLines`——即中心符号线属性里手工插入的第二种「线性中心符号线」勾连接线；
     只有一个孔的种用单个中心符号线。组内孔按图纸上从上到下、从左到右选；SolidWorks 不接受线性组时退回逐个单个。
  4. 回执说明认出几个孔共几种、删掉几个旧的、新加几组线性、几个单个、几个没接受；一个都没加上时回执失败。
- 验收：离线用例「center marks: one group per kind」「center marks: only marks on holes are redone」；真机见 VERIFY-LIVE。
- 关联组件：`b-Code/HistoryStrenua/CenterMark.cs`、`CenterMarkPlanner.cs`、`HoleScan.cs`
- 关联验证：`VERIFY-UNIT`、`VERIFY-LIVE`

### REQ-006 孔位尺寸（1.2.0）

- 目的：给视图里的孔逐个标位置尺寸、同一行一排孔再算阵列文字是纯重复劳动。
- 要求：
  1. 取视图、认孔、同心合并、分种与 REQ-003 第 1–5 条完全相同（`HoleScan` 另收集视图里的直边）。
  2. **基准**：视图里最左的竖直直边（左侧基准）与最上的水平直边（上侧基准）；同一位置有几条取最长的。找不到就失败。
  3. **每个方向、每种孔单独标**（DEC-009）：这一种里的孔按坐标归成中心线（水平方向按 X 归列、竖直方向按 Y 归行）；
     第一条从基准标，其余接着前一条标（同种孔可接着前一个孔标，不同种孔必须从基准标）。
  4. **阵列标法**：同种孔一个方向超过 4 条中心线且等距（间距差 ≤ 0.01 mm，模型尺寸）时，基准到第一条一个尺寸、
     第一条到最后一条一个尺寸，前缀 `IDisplayDimension.SetText(swDimensionTextPrefix, "(N-1) x 间距 =")`，
     值由 SolidWorks 给出总长；间距按模型 mm 取两位小数去尾零。不等距退回第 3 条的链式。
  5. **按中心线标、不按孔标**（DEC-010）：同一段「中心线 → 中心线」（含基准到中心线）在一个方向上全视图只标一次。
  6. 选择：水平尺寸的孔那一头在孔心按 `CENTERMARKSYMS` 点选中心符号线，核对选中类型为 100，SolidWorks 把尺寸连到
     符号线的竖线（`swSelEXTSKETCHSEGS`）；有一头选不到就整条改选孔边。竖直尺寸只选孔边（DEC-010）。建出来的
     `Type2` 不是线性（2/11/12）就删掉、改选孔边重建。
  7. 放置：水平尺寸在上侧基准之上、竖直尺寸在左侧基准之左；一种孔一层，第一层 8 mm、层距 6 mm（图纸），
     跨度短的在里；阵列那一种阵列尺寸在里、基准尺寸在外。没分到尺寸的种不占层。不避让相邻视图。
  8. **重新标**：先删连着这些孔的旧线性尺寸——附着孔边且圆心在孔上，或附着视图草图线且线段穿过孔心
     （草图点 → 图纸：视图位置 + 草图点 × 比例；视图旋转过则不认草图线）。孔标注、非线性尺寸、不连孔的尺寸不动。
     视图里**悬空**的线性尺寸（`IAnnotation.IsDangling`，或附着对象为空 / 类型 0）也一并删（1.3.0，DEC-012）。
     删法同 REQ-005 第 2 条（`AnnotationEraser`）。
  9. 回执说明认出几个孔共几种、删掉几个旧的、新加几个（阵列几个、连在中心线上几个）、几个没接受；
     有要加的却一个都没加上时回执失败。
  10. **尺寸链模式**（1.7.0，DEC-018，页面「尺寸链」开关，默认关）：第 3–7 条换成 SolidWorks「尺寸链」——
      **坐标尺寸**（`swOrdinateDimension`，Type2 = 1；按用户演示图），每个方向一组：
      - 0 点是基准边（用户第四轮定）：水平组是零件最左侧直边、竖直组是最上侧直边，与第 1 条的基准相同；其后每条中心线一个坐标值，
        不分孔的种类、不用阵列写法；同一条中心线上几个孔（不论哪种）算一站，取离文字最近的那个孔（水平取最上、竖直取最左）。
      - 竖直组文字排一列在左侧直边左边 14 mm，水平组排一行在上侧直边上方 14 mm；挤在一起的文字由 SolidWorks 自动折弯错开
        （间距 4.375 mm，与演示一致）。
      - 建法：选 0 点孔 → `IModelDocExtension.AddOrdinateDimension(2 竖直 / 3 水平, x, y, 0)` 只建出 0 点 → `SetPickMode` 退出 →
        选中 0 点尺寸 + 其余各站的孔 → `IModelDoc2.EditOrdinate` 一次建出整组 → `SetPickMode`。
        （真机：预选全部再 `AddOrdinateDimension` 只建 0 点；之后用 API 再选不会往组里加。）
      - 先连中心符号线（与演示一样，SolidWorks 取过孔心的横线 / 竖线）；有一个孔点选不到、或建出的值（排序后）与规划差超过 0.01 mm，
        整组删掉退回连孔边（值相同，引出线画到圆心）。孔挨得近时按孔心点选会选到邻孔的符号线，所以真机上常是连孔边。
      - 重新标照第 2 条，坐标尺寸与线性尺寸一样删（两种模式来回切不留旧的）；坐标尺寸不参与避障。
        回执里「阵列标法 P 个」换成「尺寸链模式，尺寸链 K 组」。
- 验收：离线用例「hole position: …」7 组（含 chain mode）；真机见 VERIFY-LIVE 第 8–10、21 步。
- 关联组件：`b-Code/HistoryStrenua/HolePosition.cs`、`HolePositionPlanner.cs`、`AnnotationEraser.cs`、`HoleScan.cs`
- 关联验证：`VERIFY-UNIT`、`VERIFY-LIVE`

### REQ-007 腰型孔兼容（1.3.0）

- 目的：板件上的腰型孔（长圆孔）与圆孔一样要标孔标注、中心符号线和位置；1.2 以前端头半圆被当成槽口排除，腰型孔一个都不标。
- 要求：
  1. **认端头**：圆弧有端点时，两端点中点落在圆心上（偏差 ≤ 半径 × 0.001）才算恰好半圈；孔壁、正对判据与 REQ-003 第 2 条相同。
     鼓出方向：弦法向 n = 轴 × 弦，在「圆心 + 半径 × n」处取圆弧上最近点（`IEdge.GetClosestPointOn`），离得近（< 半径/2）
     鼓向 n，否则鼓向 -n；变到图纸平面后归一。
  2. **配对**（`SlotPlanner.Pair`，在同心合并之后）：同种（组件 + 特征）、同半径（差 ≤ 0.02 mm 图纸）、两圆心连线上
     A 背着 B 鼓且 B 背着 A 鼓（夹角余弦 ≥ 0.999）；有几种配法时近的先配。配上的两端同一个编号，种名加「/腰 + 两端距离」
     （同一特征里长短不同的是两种，也不与同特征的圆孔混成一种）；配不上的半圆丢掉（开口槽口、圆弧槽不认）。
  3. **计数**：一个腰型孔算一个孔，回执写「H 个孔（含 S 个腰型孔）共 T 种」。
  4. **孔标注**：腰型孔两端都留在种里，已有标注挂在任一端都算整种标过；新标注选这一种最靠左上的那一端圆弧
     `AddHoleCallout2`（SolidWorks 对腰型孔与圆孔同一个接口，规格一次写全），放置同 REQ-003 第 6 条。
  5. **中心符号线**：两端各当一个孔（用户定，DEC-011），同种端头一组线性中心符号线带连接线，按 REQ-005 第 3 条插入，
     但 `InsertCenterMark3` 的第三个参数（槽口样式）必须给 true——给 false 时 SolidWorks 不报错、却把每个端头各建成单个。
     一个腰型孔也有两端，所以总是线性组。插入后一律读回 `ICenterMark.Style` 核对：不是线性组就按 SolidWorks 拆出的单个计数、
     不再补插。标在端头上的旧符号线按 REQ-005 第 2 条删。
  6. **孔位尺寸**：每个腰型孔只取上方那一端的圆心（两端一样高取左端）参加 REQ-006 的分种、链式、阵列与去重；
     连在任一端上的旧线性尺寸都按 REQ-006 第 8 条删。
- 验收：离线用例「slots: …」5 组；真机见 VERIFY-LIVE 第 11–13 步。
- 关联组件：`b-Code/HistoryStrenua/SlotPlanner.cs`、`HoleScan.cs`、`HoleCalloutPlanner.cs`（`Recognize` / `Representatives` / `Count`）
- 关联验证：`VERIFY-UNIT`、`VERIFY-LIVE`

### REQ-008 销钉符号（1.6.0）

- 目的：异形孔向导加了销钉孔，现场图纸却常漏了销钉符号，要一个个补。
- 要求：
  1. 取视图、认孔、同心合并与 REQ-003 第 1–4 条相同。
  2. **销钉孔只认异形孔向导做的**：孔壁所属特征类型 `HoleWzd`，`IWizardHoleFeatureData2.FastenerType2` 是各标准的销钉孔
     （`swWzdHoleStandardFastenerTypes_e` 703–712）。手工切出的孔、腰型孔端头不算。
  3. 一孔一个销钉符号：选孔边 `IDrawingDoc.InsertDowelSymbol`。已有销钉符号（注解类型 10，附着孔边；附着丢了用
     `IDowelSymbol.GetArcPoints` 的圆心，图纸坐标）所在的孔跳过，不删旧的。
  4. 回执说明认出几个销钉孔、新加几个、跳过几个、SolidWorks 拒绝几个；有要加的却一个都没加上时回执失败。
- 验收：离线用例「dowels: …」2 组；真机见 VERIFY-LIVE 第 17 步。
- 关联组件：`b-Code/HistoryStrenua/DowelSymbol.cs`、`DowelPlanner.cs`、`HoleScan.cs`
- 关联验证：`VERIFY-UNIT`、`VERIFY-LIVE`

### REQ-009 标注避障（1.6.0）

- 目的：孔标注的文字、孔位尺寸的数字压在别的孔的标注线条上，读不清，要手工一个个挪。
- 要求（用户定：不单独成指令，并进「孔标注」与「孔位尺寸」；范围本视图、只看孔相关）。1.7.0 起受页面「避障」开关控制
  （REQ-011，默认开）；关着时两条指令加完就结束，不读也不挪：
  1. **孔相关注解**：连着孔的孔标注、连着孔边或穿过孔心的线（中心符号线、中心线）的线性尺寸、标在孔上的中心符号线、
     孔上的销钉符号、穿过孔心的中心线。外形尺寸、注释、别的视图不看也不动。
  2. **文字框**：`IDisplayData.GetTextPositionAtIndex` 是左下基线点（图纸坐标），宽 `GetTextInBoxWidthAtIndex`、高
     `GetTextHeightAtIndex`、角 `GetTextAngleAtIndex`（竖直尺寸 π/2，字往 -X 长），四周留白 0.3 mm。
  3. **压到** = 别的孔相关注解的直线（显示数据里的线；销钉符号按圆的八段折线）穿过文字框，或两个文字框相交。
     站在别的尺寸的尺寸线上（共线）也算；自己的尺寸线 / 下划线不算，但孔位尺寸**自己的尺寸界线**算（跨度装不下字时整段滑到界线外）。
  4. **孔位尺寸**：「孔位尺寸」加完尺寸后逐个检查，压着就沿尺寸线方向滑，每步 0.5 mm、先正后负、最远 30 mm，取最近的不压位置；
     不换层。滑到头都压就原样留着。
  5. **孔标注**：「孔标注」加完（或全都已有）后逐个检查视图里的孔标注，压着就换角位：折点离孔心「半径 + 12 / 18 / 24 mm」，
     每档依次左上、右上、左下、右下；挑第一个不压的，都压就挑压得最少且少于现在的，再没有就不挪。文字在折点右侧时
     折点对下划线左端（SolidWorks 自动换引线侧，文字整块随标注刚性平移，下划线比文字长出 1.25 mm）。
  6. 挪完回读核对；回执末尾加「避让挪开 M 个尺寸数字 / 孔标注（K 个找不到空位、原样留着）」，没动就不写。
- 验收：离线用例「clearance: …」3 组（含过渡板真机显示数据）；真机见 VERIFY-LIVE 第 18 步。
- 关联组件：`b-Code/HistoryStrenua/Clearance.cs`、`ClearancePlanner.cs`、`HoleCallout.cs`、`HolePosition.cs`
- 关联验证：`VERIFY-UNIT`、`VERIFY-LIVE`

### REQ-010 孔标注全流程（1.6.0）

- 目的：一张图要对每个视图依次按四条孔类指令，太繁琐。
- 要求：
  1. 不用点选视图，范围是**当前图纸页**的全部视图（`IDrawingDoc.GetFirstView` 之后的视图；不切换图纸页，用户定）。
  2. 每个视图依次：销钉符号（REQ-008）→ 中心符号线（REQ-005）→ 孔位尺寸（REQ-006）→ 外轮廓（REQ-013）→ 孔标注（REQ-003）
     → 销孔标注（REQ-012）；避障与尺寸链模式照页面开关（REQ-011）。
     前四步顺序用户定；孔标注在尺寸之后，避障时尺寸都已在位。1.8.0 加的两步：外轮廓紧跟孔位尺寸（尺寸链模式下它往孔的那组
     坐标尺寸加站，孔位尺寸重标会连组删掉）；销孔标注最后（孔位尺寸重标会删掉销孔间 ±0.02 尺寸；销孔的孔标注由孔标注先加好）。
  3. 没引用模型的视图跳过；**轴测图整个跳过**（1.8.1，用户定：全流程只标各向视图）——视线在模型里三个分量都不为 0（>0.02）即轴测图

### REQ-012 销孔标注（1.8.0）

- 目的：销孔要标配合与位置公差，手工逐个改孔标注、找销孔间尺寸加公差很繁琐（DEC-019）。
- 要求：
  1. 指令 `strenua.hole.dowelfit`「销孔标注」，点一个视图（同 REQ-003 的选视图）。销孔 = 异形孔向导的销钉孔（REQ-008 的认法），腰型孔不算。
  2. **H7**：每种销孔（分种同 REQ-003）一个孔标注；已有的直接改，没有就先按 REQ-003 加一个。改孔标注里孔径那个长度变量
     （`GetHoleCalloutVariables` 里长度等于孔径的，名字带 diam 的优先）：公差类型「配合（带公差）」（`swTolFITWITHTOL` = 8）、
     孔配合 `H7`、线性显示、带括号、偏差三位小数，SolidWorks 按标准表算偏差值（如「⌀5H7(+0.012/0)」）。文字变宽后把引线折点挪回原处。
  3. **±0.02**：只在销孔与销孔之间（与别的孔、与基准之间不加）。同一种销孔里，每个方向按中心线归成站，相邻两站一段；
     同一行只有水平段，同一列只有竖直段。不跨种（真机底板不分种串出了 545 mm 的跨板尺寸）。
  4. 已有的改、没有的补：沿同一方向、两头落在这两条中心线上的线性尺寸就是这段（连孔边、连中心符号线、连同列别的孔都算），
     改成对称公差 ±0.02；没有就在两销孔之间新加（水平尺寸优先连中心符号线，同 REQ-006；文字在两孔旁 6 mm）。
  5. 「(仅销孔)」：这段与别的孔的同段尺寸重叠、被孔位尺寸去重并成一个时，尺寸后缀写「 (仅销孔)」。判法：普通模式下有别的种也想标这段
     （`HolePositionPlanner.RequestedSpans`），或已有这段尺寸连着的不是销孔；尺寸链模式不写。不再兼管时去掉本指令写的这个后缀，别的后缀不动。
  6. 「避障」开着且新加了尺寸时，最后做一遍 REQ-009 的尺寸避障。
- 验收：离线用例「dowel fit: …」3 组；真机见 VERIFY-LIVE 第 22–24 步。
- 关联组件：`b-Code/HistoryStrenua/DowelFit.cs`、`DowelFitPlanner.cs`、`DimensionScan.cs`、`DimensionGeometry.cs`
- 关联验证：`VERIFY-UNIT`、`VERIFY-LIVE`

### REQ-013 外轮廓（1.8.0）

- 目的：外形尺寸也要一键标，并与孔位尺寸同样支持尺寸链模式（DEC-019）。
- 要求：
  1. 指令 `strenua.hole.outline`「外轮廓」，放在「孔」面板（受同一组开关控制），点一个视图。基准同 REQ-006（最左竖直边、最上水平边）。
  2. 外轮廓边：竖直 / 水平直边两侧各取一点（离边 0.05 mm），有一侧朝上下左右任一方向射线不碰任何边即是。挡射线的是视图里全部直边
     和曲线边（圆弧取起点 → 弧中点 → 终点两段、整圆取八边形、别的曲线取弦）。开口槽、台阶算；封闭型腔、孔不算；斜边、圆弧不标。
  3. 每个台阶都标（用户定）：竖直外轮廓边按 X、水平外轮廓边按 Y 归成站，基准不算，最远一站即总长 / 总宽；一站多条边取离尺寸近的。
  4. 普通模式：每站一个从基准量起的线性尺寸，一站一层、近的在里，第一层在现有尺寸文字最外处再往外 6 mm（没有现有尺寸时 8 mm）。
  5. 尺寸链模式：每个方向把还没有的站加进 0 点连在基准边上的那组坐标尺寸（`EditOrdinate`），组里已有同值的站（孔恰好在那条线上）跳过；
     没有组就照 REQ-006 新建（0 点在基准边、文字离直边 14 mm）。加完核对值，对不上整批删掉。
  6. 重新标：两种模式都先删旧的外轮廓线性尺寸（两头都是外轮廓直边，含用户手标的外形尺寸）；普通模式另删外轮廓坐标尺寸
     （两头都是外轮廓边的成员；0 点只在它那组没有孔时才删）。孔位尺寸重标（REQ-006）删坐标尺寸组时连带删掉这里加的站。
  7. **跨视图不重复**（1.8.1，DEC-020，用户定：高度在视图 a 标了就别在视图 b 再标）：当前图纸页上同一模型（文件 + 配置）、不是轴测图的
     别的视图里，每个两头都是模型直边的线性 / 坐标尺寸把它两头那两个**模型面**连起来（并查集，`OutlineCoverage`）；本视图一站
     （基准面 → 站面）在别的视图里已连通——直接标过或经别的面串起来——就不标。按面认、不按数值：视图图纸 X / Y 在模型里的方向由
     `ModelToViewTransform` 变换三根模型轴得出（`ViewFrame`），方向相反的视图（左视 / 右视、俯视的深度）也认得是同一个面。
     重标时本视图里这样的旧外轮廓尺寸照第 6 条删掉不再加；尺寸链模式另删组里已被别的视图定了的外轮廓站，成员删光的 0 点一起删。
     回执写「N 站别的视图已标跳过」。单独按「外轮廓」时同样看这一页别的视图。
- 验收：离线用例「outline: …」6 组（1.8.1 加跨视图 3 组）；真机见 VERIFY-LIVE 第 25–27、30 步。
- 关联组件：`b-Code/HistoryStrenua/Outline.cs`、`OutlinePlanner.cs`、`OutlineCoverage.cs`（1.8.1）、`HoleScan.cs`（`CurveOutline`、`Frame`、`ModelKey`）、`HolePosition.cs`（坐标尺寸建组 / 加站）
- 关联验证：`VERIFY-UNIT`、`VERIFY-LIVE`

### REQ-015 新建工程图与出图各步（1.9.0）

- 目的：用户每张零件图都要手工选模板与比例、放主视图、投影视图、轴测图、贴技术要求（2026-025 台面2机器 15 张手工图都是这样做的，DEC-021）；

  用户定（DEC-022）：拆成单独的指令，人手工、AI 经 MCP 都能一步步做、中间改。
- 要求：
  1. 新类「出图」（命令类 `drawing`）五条指令，各自单独可按，也由「一键出图」（REQ-016）依次调用：
     - `strenua.drawing.create`「新建工程图」：零件 → 新图，选模板与比例（第 5 条，按整套视图估）、放主视图（第 3 条），主视图放在整套排好时它该在的位置（估计）。
       活动文档是零件就给它出图；是装配体就用选中的零件（选零件上的面、边也算；先选后按、先按后选都行，最多等 60 秒；
       选到子装配体、压缩 / 轻化的零件失败并说明）；是工程图失败。零件必须保存过。
     - `strenua.drawing.project`「投影视图」：当前工程图，从选中的视图（没选或选的是轴测图就从主视图，第 10 条）按第 4 条补投影视图；
       那个方向（可换边的两个方向都算）已有视图就不加；可换边的按当前图幅与比例挑放得下的那边（同第 5 条的估计）；新视图贴着父视图放
       （间距同第 7 条：4 mm 加该留的标注空间），别的不动；新视图出图框或压到标题栏等时回执提示按「排版」。
     - `strenua.drawing.iso`「轴测图」：从选中的视图（没选就从主视图）右上斜投影一个轴测图，放离主视图那一行最近的空地（原比例、往下两档依次试），
       躲开现有视图连同标注空间与禁区；图纸页上已有轴测图就不加。
     - `strenua.drawing.note`「技术要求」：第 8 条；先放标题栏正上方靠右、再左下角、再找空地，躲开现有视图连同标注空间；图框里已有就不加。
     - `strenua.drawing.arrange`「排版」：第 7 条，按实际外框重排当前图纸页。
  2. **读零件**（`PartScan`）：包围盒、全部平面的外法向、全部圆柱面（轴、半径、凹凸、整圈与否、所属特征、孔口朝向）、平面上的窗口
     （内环里不是单独一条整圆边的：方窗、异形切口、腰型孔口，每个记一次所在平面的法向）。凹凸判法同认孔（DEC-005）；
     孔 = 内凹整圈圆柱面按同轴并成一个，孔口取最粗那一截的（整圆边旁边与轴垂直、外法向背着圆柱面的平面），沉头孔只朝沉头那面。
  3. **主视图**：六个标准命名视图之一（中文版「*前视」等，退回英文名），不转角度。三根轴各打分：沿它的孔、窗口、R1 以上的圆弧面各 2 分，取最高；
     平分取零件在它上面最薄的；回转体（最大外圆柱面包住截面）不看端面。正反两面取孔口多的那面，一样多取正向。
  4. **投影视图**（按建出的主视图实际朝向、图纸的第一 / 第三角投影定）：沿图纸横向有孔或窗口就加左 / 右视图、沿竖向有就加上 / 下视图，
     摆在能看到孔口多的那一侧（第一角投影里右视图看零件左侧、下视图看零件上面）；都没有孔而有圆弧面只加一个（圆弧面多的方向）；
     都没有就加一个看厚度的（宽件下边、高件右边）。后两种「可换边」：选图幅时两种摆法都试。另从主视图右上斜投影一个轴测图。
  5. **模板与比例**：模板取 SolidWorks「文件位置 → 文件模板」各目录下的 `*.drwdot`，按文件名认图幅（A0–A4，「横 / 纵」），零件图只用名字带
     「零件」的（没有才用别的）、有横放的只用横放的，图幅从小到大；比例取 2:1（小件）、1:1、1:2、1:3、1:5、1:10、1:20、1:50、1:100。

      否则第一个不是投影 / 辅助 / 剖视 / 局部视图、也不是轴测图的模型视图，再没有就第一个不是轴测图的视图；它引用装配体时失败（只给零件图）。
      其余视图：别的零件、从别的视图投影出来的（基视图 `IView.GetBaseView` 不是主视图——真机：左视图下面再投的视图曾被当成主视图的下视图、比例被误降一档）
      归「其他」；轴测图（视线三个分量都不为 0）取第一个；视线沿主视图图纸 X / Y 的按投影角归左右 / 上下（第一角：看零件左侧的在右、看上面的在下；

### REQ-017 圆角标注（1.9.0）

- 目的：用户图上的圆角（连接件 R5 / R10 / R5、夹爪 R101 / R30 / R5 / R5）都是一个个手加的 R 尺寸。
- 要求：
  1. 指令 `strenua.drawing.fillet`「圆角标注」，放「出图」面板，点一个视图（同 REQ-003 的选视图）。

     同一圆角被切成几段（图纸上圆心、半径差 0.05 mm 内）算一个。

## 系统架构

```
Aurora PowerSW 控制面板按钮 ──strenua.quick.<键>──▶ strenua.hole.callout 等（总线指令）
Aurora 开关 ──strenua.option.clearance / chain──▶ StrenuaOptions（options.json）
                                   │
                           QuickCommandRunner（单并发、取消、执行状态；带上 StrenuaOptions）
                                   │  新建 STA 线程
                           SolidWorksSession.AttachRunning（GetActiveObject）
                                   │
                           SolidWorksApi（运行时加载 Interop，按接口名反射调用，
                                   │   忙时重试 RPC_E_CALL_REJECTED，收工统一释放 COM）
                           HoleFlow（当前图纸页逐个视图，依次调下面六条）
                           HoleScan（取视图 → 取边 → 判孔 / 腰型孔端头 / 销钉孔；直边、曲线边近似）→ SlotPlanner（配对）
                             ├─ DowelSymbol（DowelPlanner → InsertDowelSymbol）
                             ├─ CenterMark（CenterMarkPlanner → 删旧 → InsertCenterMark3 线性组 + 连接线）
                             ├─ HolePosition（HolePositionPlanner → 删旧 → Add{Horizontal,Vertical}Dimension2 + 前缀 → Clearance 滑开）
                             ├─ Outline（OutlinePlanner → 删旧 → 线性尺寸分层 / 加进坐标尺寸组）
                             ├─ HoleCallout（HoleCalloutPlanner → AddHoleCallout2 → Clearance 换角位）
                             └─ DowelFit（DowelFitPlanner → 孔标注变量 H7 → 销孔间 SetValues ±0.02 / 新加）
                           DimensionCheck（当前图纸页逐个视图：DimensionScan → DimensionCheckPlanner，只读）
                           DrawingCreate（1.9.0：PartScan 读零件 → DrawingPlanner 挑主视图 / 投影视图 / 模板比例 / 排版
                                   │   → NewDocument、CreateDrawViewFromModelView3、CreateUnfoldedViewAt3、InsertNote、IView.Position）
```

## 对外约定（2026-10-02 自原《模块API》移入）

各条指令的参数与示例读注册时的自描述（`diana.docs.read domain=strenua`）；下面是自描述装不下的回执与 Data 形状。

- 共同前提：SolidWorks 必须已在运行，本模块只附着，不启动、不隐藏、不退出它；一次只执行一条快捷指令，第二条直接失败回执「还在执行」。
  执行中经 `CommandContext.Progress` 逐步报告，消费方不必从结论里复述过程。

  - `strenua.hole.dowelfit`：`视图「X」：D 个销孔共 T 种，F 种孔标注已带 H7（其中 A 个孔标注是新加的），G 种没改成；销孔间尺寸 N 个带 ±0.02（新加 M 个，S 个兼管别的孔写了「(仅销孔)」），K 个没成，避让挪开 …。`；
    没有销钉孔时成功无改动；有没改成的（H7 或 ±0.02）回执失败。
  - `strenua.hole.outline`：`视图「X」：外轮廓 N 站，新加 M 个（先删掉旧外轮廓尺寸 D 个），K 个 SolidWorks 没有接受。`；尺寸链模式写成
    `尺寸链模式新加 M 个坐标尺寸，P 站组里已有同值跳过`；找不到基准边失败；一个都没加上且有失败时回执失败。

    主视图与理由；图幅与比例按整套视图估（列出该有的投影视图与理由、轴测图、技术要求）及理由；接下来按哪几步。

  - `strenua.drawing.project`：首行 `投影视图：从视图「M」加了 N 个，贴着它放（别的视图没动，整页重排按「排版」）。`（都有了：`投影视图：视图「M」该有的投影视图都有了，没有再加。`），
    其后每个计划的投影视图一行（`· 右边「V」：理由。` 或 `· 理由：左边已有「V」，不再加。`），出图框时加一行提示排版；SolidWorks 投影不出来时回执失败。
  - `strenua.drawing.iso`：`轴测图：从视图「M」斜投影出「V」，放在空地上（，比例缩成 1:10）。`，找不到空地时注明放在压得最少处；已有：`轴测图：图纸页上已有轴测图「V」，没有再加。`；投影不出来失败。
  - `strenua.drawing.note`：`技术要求：已放进图纸，放在标题栏正上方（出处）。`（或「放在空地上」「…放在了压得最少处…」）；图框里已有：`技术要求：图框里已经有一条带「技术要求」的注释，没有再加。`；SolidWorks 不接受注释时失败。
  - `strenua.drawing.arrange`：首行 `排版：主视图「M」、右边「V」、轴测图「I」、技术要求按实际大小排开，比例 1:5。`，其后（有才写）比例从几降到几及原因、轴测图缩成的比例、
    「其他」视图没挪、找不到空地的东西；降到底还排不下时首行写「尽量摆开」并回执失败。
  - 出图各步（投影视图、轴测图、技术要求、排版）共同失败：活动文档不是工程图；当前图纸页没有引用零件的正交视图；主视图引用的是装配体。
  - `strenua.drawing.auto`：首行 `一键出图：新图建好并标完（未保存）。`（或「…，K 步没成（排版、孔标注全流程…）。」并回执失败），
    其后依次是新建工程图、投影视图、轴测图、技术要求、排版、孔标注全流程、全图圆角的原回执（某步抛出的前置条件失败写成「步骤名：原因」）。
  - `strenua.drawing.filletall`：首行 `全图圆角：当前图纸页 N 个视图都已做完（，K 个没成（视图「X」…））。`，其后每视图一行 `· 原回执`；有没成的回执失败；
    没有要标的视图时成功无改动。
  - `strenua.drawing.fillet`：`视图「X」：C 个圆角，新加 N 个 R 尺寸，D 个是 R1（技术要求未注圆角 R1）不标，E 个已有尺寸跳过，K 个 SolidWorks 没有接受。`；
    没有圆角、都不用加时成功无改动；有要加的却一个都没加上时回执失败。
- `strenua.check.snapshot`（1.9.0）：`图纸截图：「标题」当前图纸页已存成图片 <完整路径>`，`Data` 为 `null`；路径在模块数据目录 `snapshots` 下，只留最近 30 张。
  活动文档不是工程图、SolidWorks 没存出来时回执失败。
  - 失败：SolidWorks 未运行 / 未注册；没有打开文档或活动文档不是工程图；60 秒内没点选视图；视图不引用模型；已被取消；旧注解删三遍仍删不掉（此时不重标）；
    孔位尺寸找不到竖直或水平直边做基准；确有要加的却一个都没加上。成功但无改动：视图里没有正对图纸的孔（孔标注另含「孔都已有标注」）。
- `strenua.quick.cancel`：不失败，没有在跑的指令也回成功；被取消的那条回执失败「已取消」，已经加上的标注不回滚。
- `strenua.option.clearance` / `strenua.option.chain`：`Data` 为 `null`；改了回「PowerSW「避障」已打开。」之类，存档失败时在后面注明；
  省略 `value` 回「当前开 / 关」；`value` 不是 true / false 时失败。
- `strenua.quick.list`：`Data` 为 `IReadOnlyList<IReadOnlyDictionary<string,string>>`，每行键 `id`、`title`、`class`、`usage`、`state`、`result`、`time`（`HH:mm:ss`，未执行过为空）；
  `Message` 末行是「避障：开；尺寸链：关」；
  `state` 取值：`就绪`、`附着 SolidWorks`、`等待点选视图`、`识别孔`、`加销钉符号`、`加标注`、`删旧符号线`、`加中心符号线`、`删旧尺寸`、`加尺寸`、`避障`、`孔标注加 H7`、`销孔间 ±0.02`、`检查`、
  1.9.0 加的 `等待点选零件`、`读零件`、`新建工程图`、`建主视图`、`加投影视图`、`加轴测图`、`加技术要求`、`排版`、`加圆角尺寸`、`截图`，以及 `完成`、`失败`、`已取消`。
- 界面内部协议 `strenua.ui.describe / actions` 声明 `HiddenReason`，不要跨模块调；页面 owner 与场景 id 为 `HistoryStrenua`，页面 id `powersw`。
