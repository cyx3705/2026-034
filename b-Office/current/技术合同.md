# HistoryStrenua 技术合同

本文件合并当前有效的需求与架构。关键决策单独保存在 `有效决策.md`；已失效内容移入
`../history/`，不得继续作为实现依据。

## 现行需求

### REQ-001 快捷指令登记表

- 目的：PowerSW 会持续加按钮，加一个按钮不应改页面描述、动作声明和指令注册三处。
- 要求：每条快捷指令是一条 `QuickCommand`（键、指令名、按钮文字、用法、执行体），登记在
  `QuickCommands.All`。页面按钮（每行最多 4 个，「取消」排最后）、动作声明（`strenua.quick.<键>`）、
  总线指令、状态表行全部由登记表生成。1.0.0 只有无参按钮；将来带参数时在 `QuickCommand` 上加参数表，
  由页面生成器渲染成按钮前的输入框并经动作占位符传入，已有无参指令不受影响。
- 验收：离线用例「buttons, actions and commands line up」「button rows wrap」「status rows」。
- 关联组件：`b-Code/HistoryStrenua/QuickCommand.cs`、`StrenuaPage.cs`、`HistoryStrenuaModule.cs`
- 关联验证：`VERIFY-UNIT`

### REQ-002 附着而不接管

- 目的：PowerSW 作用于用户手上的 SolidWorks，任何「顺手」的接管都会打断用户。
- 要求：只经运行对象表附着已运行的 SolidWorks（`GetActiveObject`），没开就失败并说明；
  不改 `Visible` / `UserControl`、不 `ExitApp`；收工只释放本次经手的 COM 引用。
  一次只跑一条快捷指令（它们共用同一个选择集），第二条直接回执「还在执行」。可取消。
- 验收：VERIFY-LIVE 第 1、5 步。
- 关联组件：`b-Code/HistoryStrenua/SolidWorks/`、`QuickCommandRunner.cs`
- 关联验证：`VERIFY-LIVE`

### REQ-003 孔标注

- 目的：给工程图视图里的孔逐个加孔标注是纯重复劳动。
- 要求：
  1. 活动文档必须是工程图。当前选择里有视图（或视图里的任何对象）就用它；否则等用户点选，最多 60 秒。
  2. 孔的判据是几何：整圈圆边（无端点）、旁边有一张**内凹**且同半径的圆柱面（`FaceInSurfaceSense=false`）、
     轴线正对图纸（视图空间里与法向夹角余弦 ≥ 0.999）。异形孔向导的各类孔与手工切出的圆孔都算；
     槽口端部半圆、凸台外圆、侧视投影不算。
  3. 装配视图逐个可见组件取边，几何先乘组件变换再乘视图的模型→图纸变换。
  4. 图纸上圆心相距不到 0.02 mm 的圆边算同一个孔（沉头与底孔、通孔上下口），取半径最小的那条。
  5. 视图里已有孔标注指向的孔跳过；新标注放在孔右上方 45°、离孔边 5 mm，按从上到下、从左到右依次添加。
  6. 回执说明新加几个、跳过几个、SolidWorks 拒绝几个；确有要加的孔却一个都没加上时回执失败。
- 验收：离线用例覆盖合并、跳过、排序、放置、正对判定、孔壁判定；真机见 VERIFY-LIVE。
- 关联组件：`b-Code/HistoryStrenua/HoleCallout.cs`、`HoleCalloutPlanner.cs`
- 关联验证：`VERIFY-UNIT`、`VERIFY-LIVE`

### REQ-004 页面

- 要求：Aurora 描述协议 V1，一页 `powersw`（标题 PowerSW，中央，场景 `HistoryStrenua`）：
  控制面板「SolidWorks 快捷指令」+ 说明行 + 状态表（指令 / 用法 / 状态 / 上次结果 / 时间）。
  owner 与场景由指令域推出（`strenua` → `HistoryStrenua`）。执行中状态格实时更新（附着、等待点选视图、识别孔、加标注）。
- 验收：离线用例「page owner follows domain」；合同检查的 owner 规则；VERIFY-ACCEPT。
- 关联验证：`VERIFY-UNIT`、`VERIFY-FULL`、`VERIFY-ACCEPT`

## 系统架构

```
Aurora 页面按钮 ──动作 id──▶ strenua.hole.callout（总线指令）
                                   │
                           QuickCommandRunner（单并发、取消、状态表、刷新页面）
                                   │  新建 STA 线程
                           SolidWorksSession.AttachRunning（GetActiveObject）
                                   │
                           SolidWorksApi（运行时加载 Interop，按接口名反射调用，
                                   │   忙时重试 RPC_E_CALL_REJECTED，收工统一释放 COM）
                           HoleCallout（取视图 → 取边 → 判孔 → HoleCalloutPlanner → AddHoleCallout2）
```

| 组件 | 职责 | 输入 | 输出 |
| --- | --- | --- | --- |
| `HistoryStrenuaModule` | 注册指令 | 宿主上下文 | 6 条 `strenua.*` 指令 |
| `StrenuaPage` | 页面描述、动作声明、状态行 | 登记表、执行状态 | JSON / 行 |
| `QuickCommandRunner` | 执行编排 | 快捷指令、命令上下文 | 回执 |
| `SolidWorks/*` | 附着与 COM 调用 | 运行中的 SolidWorks | COM 对象 |
| `HoleCalloutPlanner` | 纯几何规划 | 候选孔边、已标注孔心 | 标注目标 |

模块内部类型全部 `internal`，不构成跨模块消费面；跨模块只经总线（见 `../package/模块API.md`）。

## 外部接口

| 接口 | 方向 | 格式或协议 | 所有者 |
| --- | --- | --- | --- |
