# HistoryStrenua 有效决策

这里只保留当前仍有效、会影响后续实施的决策。

## DEC-001 独立成模块，不并入 HistoryMinerva

- 状态：已接受
- 日期：2026-09-29
- 背景：最初设想是 Minerva 5.0 新增 PowerSW 页。
- 决策：新开模块 HistoryStrenua（2026-034），Minerva 保持转换插件定位。
- 原因：两者用 SolidWorks 的方式相反——Minerva 转换会启动专属进程、隐藏界面、关用户交互、可能退出；
  PowerSW 这些一样都不许做。放一起迟早有人把一边的做法用到另一边。且 Minerva 体量大、门禁重，
  每加一个按钮都要全量回归并给 Minerva 发版不划算。
- 后果：借用了 Minerva Worker 里约 200 行 SolidWorks 通用做法（Interop 加载、按接口名调用、COM 释放）。
- 替代或废止条件：出现第三个需要 SolidWorks 访问层的模块时，再议抽成共享程序集。

## DEC-002 进程内 STA 线程，不起 Worker 进程

- 状态：已接受
- 日期：2026-09-29
- 背景：Minerva 用独立 Worker 进程，是为了隔离 FeatureWorks 崩溃和长批处理。
- 决策：快捷指令在模块进程内新建 STA 线程执行，一次一条。
- 原因：快捷指令短（附着、等点选、若干次 API 调用），没有崩溃源需要隔离；单 dll 部署更轻。
- 后果：宿主用可卸载装载上下文，其中的类型不能参与 COM 互操作。因此模块内**不定义任何 `[ComImport]` 类型**，
  Interop 用 `AssemblyLoadContext.Default` 加载；没有 OLE 消息过滤器，改为对
  `RPC_E_CALL_REJECTED` / `RPC_E_SERVERCALL_RETRYLATER` 限时 30 秒重试。
- 替代或废止条件：出现长时间或可能崩溃的快捷指令时，给那一条单独起 Worker。

## DEC-003 孔按几何认，不按特征认

- 状态：已接受
- 日期：2026-09-29
- 决策：见技术合同 REQ-003 第 2 条。
- 原因：「全部类型的孔」包括异形孔向导孔、手工切孔、阵列/镜像出的孔和导入件里的孔；
  按特征认只能覆盖第一种，也拿不到阵列实例在视图里的位置。
- 后果：被切分成两段的圆柱孔（部分导入件）认不出来；开口槽口的端部半圆被有意排除（1.3.0 起腰型孔两端半圆配对后认，见 DEC-011）。
- 替代或废止条件：用户反馈漏标的孔类型时，按实际几何补判据。

## DEC-005 FaceInSurfaceSense 为 true 表示面法向与曲面法向相反

- 状态：已接受
- 日期：2026-09-29
- 背景：1.0.0 首轮按 API 文档字面（true = 同向）判孔壁，用户那张真实工程图（WTJYQ-03-03 移动底板）一个孔都没认出。
- 证据：同一零件上，最高平面（外法向必为 +Z）曲面法向 +Z、该值 false；最低平面（外法向必为 -Z）曲面法向 +Z、该值 true；
  全部 20 张孔壁圆柱面曲面法向背离轴线、该值 true。SolidWorks 2025 SP5。
- 决策：面法向 = 曲面法向 ×（该值 ? -1 : +1）。圆柱面的曲面法向不假定朝外，现场在圆上取点 `EvaluateAtPoint` 求出。
- 后果：判据只依赖这一个有标定证据的约定；单元测试把实测组合钉住。
- 替代或废止条件：换 SolidWorks 大版本后若孔又全认不出，先重做这组标定。

## DEC-006 每种孔只标一次

- 状态：已接受
- 日期：2026-09-29
- 背景：首轮每个孔都加标注，真机上 6 个 M6 孔各带一行「6× M6-6H 完全贯穿」，还与相邻标注重叠。
- 决策：按（组件、孔壁所属特征、孔径）分种，每种只标最靠左上的一个；种里有一个已标就整种跳过。用户确认此规则。
- 原因：SolidWorks 孔标注自带「N×」计数，这是制图惯例的一组一标。
- 后果：不同特征做出来的同规格孔会各标一次（SolidWorks 也会分别计数）。

## DEC-008 孔标注放左上方，按下划线对准

- 状态：已接受（取代 1.0.0 的「右上方 45°、离孔边 5 mm」）
- 日期：2026-09-30
- 背景：1.0.0 把标注文字放在孔右上方，文字压在视图里面。用户在移动底板上手工把三个标注都挪到左上方：
  文字在左、下划线右端接一段斜向右下的引线到孔，说「这样清爽一些」。
- 证据：用户摆好的三处，折点相对孔心为 (-7.8,+13.6)、(-9.8,+9.9)、(-18.9,+11.0) mm，引线 30°–60°。
- 决策：取其规律——折点在孔心左上 45°、离孔心「半径 + 12 mm」；生成后按显示数据里的下划线右端平移对准。
  `IAnnotation.GetPosition` 是文字块的水平中点、首行高度，不是折点，不能直接用来定位。
- 后果：文字向左延伸，孔靠近图纸左缘时文字可能伸出视图，需要手工挪。

## DEC-007 中心符号线一律「线性 + 连接线」、按种成组、先删后标

- 状态：已接受
- 日期：2026-09-30
- 背景：用户要求 1.1 加第二条指令：还是认全部的孔，但给视图里的孔全部重新标中心符号线，一律用带连接线的那种（手工插入选项的第二种）。
- 决策：分种沿用孔标注（DEC-006）；一种一组线性中心符号线并打开线性连接线，单孔的种用单个；
  执行前删掉标着这些孔的旧中心符号线（不在孔上的不动）。
- 证据：真机移动底板上，2×3 的 M6、2×2 的沉头孔、一对 Ø4 各成一组，连接线沿行列连好；连跑两次结果相同、不重复。
  `EditDelete` 没有返回值，删掉几个靠回读计数；第一遍删除偶有漏删，所以回读重删。
- 后果：不同特征做出来、恰好排成一行的孔不会连成一组。
- 替代或废止条件：用户要按位置（而非按种）连线时，再加按行列分组的规则。

## DEC-009 孔位尺寸：左上基准、同种链式、超过 4 个等距用阵列标法、删旧重标

- 状态：已接受
- 日期：2026-09-30
- 背景：用户要求 1.2 加第三条指令，把视图里孔的位置全部自动标出来，给了导轨立板 11 孔的样图（「10」「30」「10 x 60 =600」）。
- 决策（用户逐条定）：基准一律是左侧和上侧；同种孔可以从前一个孔标，不同种孔必须从基准标；同种孔一个方向超过 4 个
  用阵列标法，只标第一个孔的位置，再一个尺寸从第一个标到最后一个，文字「(孔数-1) x 间距 = 总长」。
  范围是点一个视图（与前两条一致，不是整张图页）；重复按时删掉孔上的旧位置尺寸重标；超过 4 个但不等距时退回逐个链式。
- 证据：真机导轨立板 View2 生成「10」「10 x 60 =600」「30」，与样图一致；View1 生成「40」「9 x 60 =540」「10」，
  与用户手工标的「9 x 60 = 540」同值。
- 后果：放置不避让相邻视图——移动底板上方投影视图离主视图 1 mm，水平尺寸压在投影视图上（待用户定是否要自动避让）。

## DEC-010 孔位尺寸按中心线标，水平尺寸连中心符号线

- 状态：已接受
- 日期：2026-09-30
- 背景：首轮真机移动底板上，沉头孔与中间那对 Ø5 孔在同一对水平中心线上，各自链式标了一遍「65」。用户：
  「标注按照中心线去标，不标注孔，这样并排的孔标注不会重复」，并指出重复；另要求尺寸离图形近一点。
- 决策：同一段「中心线 → 中心线」全视图只标一次；水平尺寸在孔心点选中心符号线加尺寸（SolidWorks 连到其竖线，
  与用户手工「9 x 60 = 540」的附着方式相同，类型 24）；竖直尺寸连孔边。第一层 10→8 mm、层距 8→6 mm。
- 证据（SW 2025 SP5）：在孔心按 `CENTERMARKSYMS` 点选得类型 100；与竖直基准边加水平尺寸得线性、附着 [1,24]；
  与水平基准边加竖直尺寸，点选偏移 0/0.3/1 mm、先后顺序对调，一律附着竖线、建成角度尺寸（type 3，值 90°）；
  偏 2 mm 就点空改选了孔边。`ICenterMark` 无取线段的方法，`IView.GetCenterMarks` 返回空，
  按 `EXTSKETCHSEGMENT` 坐标点选选不中。视图草图线坐标 = 模型尺寸、原点在视图位置。
- 后果：竖直尺寸的界线从孔边引出而不是从中心符号线的横线端头引出；数值相同。
- 替代或废止条件：找到能单独选中心符号线横线的途径时，竖直尺寸也改连中心线。

## DEC-011 腰型孔：端头配对、孔标注一次、中心符号线两端各一、孔位只标上端

- 状态：已接受
- 日期：2026-09-30
- 背景：用户要求 1.3 把孔标注、中心符号线等都兼容腰型孔。
- 决策（用户定）：
  - 孔标注：SolidWorks 里腰型孔与孔一样直接选中加孔标注，一次成型，不另标长宽——按种标一次，与圆孔同规则。
  - 中心符号线：沿用第二种（线性 + 连接线），**一个腰型孔识别为两侧的两个孔各标一次**。
  - 孔位尺寸：直接标在腰型孔**上方那个圆**的圆心上。两端一样高（横腰型孔）时用户没有说，取左端（与阅读顺序一致）。
- 认法：仍按几何（DEC-003）。恰好半圈的端头圆弧 + 内凹同半径圆柱面；按鼓出方向两两配对，互相背对着鼓才是一对——
  首尾相接排成一列的腰型孔，相邻两孔相对的端头是互相朝着鼓的，不会配错。配不上的半圆（开口槽口）照旧不认。
- 证据（SW 2025 SP5，WTJYQ-03-05 过渡板 View2，4 个沉头腰型孔 + 2 个 Ø5.5）：6 个孔（含 4 个腰型孔）共 2 种全部认出；
  选腰型孔端头圆弧 `AddHoleCallout2` 得「4 x 9 X 15 完全贯穿 / ⌴15 ↧9」；尺寸连圆弧量到圆心（10、24）；
  `InsertCenterMark3(线性, false, false)` 选 8 个端头圆弧 → 8 个单个（Style=2），改 `slot=true` → 一组线性（Style=3），
  打开连接线后行列相连，与圆孔的线性组一致。
- 后果：圆弧槽（端头不共线）不认；同一特征里长度不同的腰型孔各算一种。
- 替代或废止条件：用户要腰型孔另标长度或中心距时，再加规则。

## DEC-012 孔位尺寸重标时删掉悬空的线性尺寸

- 状态：已接受
- 日期：2026-09-30
- 背景：1.3.0 真机上发现（1.1 起就有）：「中心符号线」删旧符号线时，挂在上面的位置尺寸悬空；悬空尺寸读不出连着什么，
  「孔位尺寸」认不出它是旧的，重标后新旧叠在一起。
- 决策（用户定）：「孔位尺寸」重标时，视图里悬空的线性尺寸一律算旧的删掉。
- 后果：别的原因（模型改动等）悬空的线性尺寸也会被删；非线性（直径、角度）悬空尺寸不动。

## DEC-017 1.6.0 销钉符号、标注避障并进标注指令、孔标注全流程

- 状态：已接受

  - 全流程固定做五件事（销钉 → 中心符号线 → 孔位尺寸 → 孔标注，后两步带避障），范围是**当前图纸页**全部视图，做完才结束。
- 我定的细节：销钉孔按 `FastenerType2` 703–712 判（`Type` 是孔细类，不能用）；孔位尺寸只沿尺寸线滑（不换层，0.5 mm 一步、最远 30 mm）；

  全流程某步失败不中断。
- 证据（SW 2025 SP5，用户开着的 WTJYQ-03-05 过渡板，未保存）：`InsertDowelSymbol` 选孔边一次一个，注解类型 10、附着孔边、无显示数据，
  `GetArcPoints` 为图纸坐标；文字框锚点 = 左下基线（ref=1）；孔标注右移 50 mm 后 SolidWorks 自动把引线换到左侧。
  全流程 4 个视图约 13 秒，连跑多遍 View2 恒为 2 组中心符号线、7 个孔位尺寸，避让挪开 4 个数字（「9.50」滑到界线外、「25」留在跨度里让开外层界线、
  「10」放到跨度外、「24」让开「10」伸出的尺寸线）。
- 顺带修掉（1.3 起潜伏、本轮连跑才暴露）：悬空尺寸的附着对象读回 null 或失效对象，`AttachedCircleCenters` / `AttachedLines` 原先直接调用报错；
  有尺寸附着类型报 1（边）、对象却是草图线段（穿过孔心的中心线），按类型码 24 筛认不出、删不掉，重标后叠成两个——改为每个附着对象都试读成草图直线。
- 后果：避障不避让孔本身的轮廓与非孔相关注解；该图没有销钉孔，销钉孔识别只有离线用例与接口真机验证，待有销钉孔的图纸再测。
- 替代或废止条件：用户要避让外形尺寸或换层时，扩大障碍范围或加换层规则。

## DEC-020 1.8.1 外轮廓跨视图不重复、全流程跳过轴测图

- 状态：已接受
- 日期：2026-10-04
- 关联：REQ-013（第 7 条）、REQ-010（第 3 条）、REQ-014。来源：用户「把添加外轮廓尺寸的方法改了，不同视图的外轮廓标注别重复，
  比如高度在视图 a 中标注了就别在 b 中标注；在全标注的指令中我们只能标各种视图，不能标注轴测图，把轴测图排除在全标注命令以外」。
- 决策（用户定）：同一零件的外轮廓尺寸在一页上只标一处；全流程不碰轴测图。
- 我定的细节：
  - 「标过」按**模型面**判，不按数值：每个两头都是模型直边的尺寸连起它两头的面，本视图一站的基准面与站面在别的视图里连通即标过
    （直接标过，或像「总高 + 下边到台阶」那样串起来）。按数值会漏掉基准在零件两头的视图（右视图从上量、仰视图从下量，数不同面相同），
    也会把碰巧同值的两个不同台阶误当成一个。
  - 视图朝向由 `ModelToViewTransform` 变换三根模型轴得出：变换后的三个向量是旋转矩阵的三列，图纸 X / Y / Z 在模型里的方向是三行；
    模型点沿图纸 X 方向的坐标 = (图纸 X − 模型原点的图纸 X) ÷ 比例，不用求逆。面的方向取规范符号，方向相反的视图也对得上。
  - 只比同一模型（`GetReferencedModelName` + `ReferencedConfiguration`）的视图；范围是当前图纸页（同全流程）；轴测图的尺寸不算数。
  - 先后：全流程按视图顺序，前面的视图先标全、后面的只补；单独按「外轮廓」时以这一页其余视图为准。重跑时前面视图若看到后面视图的旧尺寸
    会先让给它，后面视图重标时不再跳过——结果仍不重复，只是落在哪个视图可能与首跑不同。
  - 轴测图 = 视线三个分量都 >0.02（约 1.1°）；辅助视图（视线垂直于某根轴）不算，照常标。「未标尺寸」检查同样不查轴测图、外轮廓按同一套面连通判。
  - 尺寸链模式不删组，只删组里已被别的视图定了的外轮廓站，成员删光的 0 点一起删。
- 证据：离线用例 3 组（主 / 右 / 俯三视图朝向、方向相反同面、等轴测 / 三等角 / 辅助视图判定、直接标过 / 串起来 / 坐标尺寸 / 连孔不收、
  尺寸链组里删已定的站与 0 点）。真机待测（VERIFY-LIVE 第 30–31 步；本轮 SolidWorks 未运行）。
- 后果：后面视图里用户手标的、与前面视图重复的外形尺寸（两头都是外轮廓边）重标时会被删掉；装配视图按顶层装配的面比，
  不同组件的同位置面会被当成同一个面。
- 替代或废止条件：用户要指定由哪个视图标某个方向（如高度固定标在侧视图）时，加视图优先级；要跨图纸页去重时扩大范围。
