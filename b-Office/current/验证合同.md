### VERIFY-LIVE 步骤

1. SolidWorks 未运行时按「孔标注」：回执失败「SolidWorks 没有在运行」，且没有 SolidWorks 进程被启动。
2. 打开一张含零件视图的工程图（视图里有通孔、螺纹孔、沉头孔、凸台），先点视图再按「孔标注」：
   每种孔一个标注且带「N×」，凸台无标注，沉头孔只算一种；标注在孔的左上方，文字下划线右端接 45° 引线到孔。
3. 再按一次：回执「都已有孔标注」，没有新标注。
4. 先按按钮再去点另一个视图：控制台提示等你点视图，点选后完成；装配视图同样成立。
5. 按按钮后不点视图、按「取消」：回执已取消；执行前后 SolidWorks 窗口与可见状态不变。
6. 视图里先有若干单个中心符号线（含一个标在圆角上的），按「中心符号线」：孔上的旧符号线全删，每种孔一组线性中心符号线且连接线打开，单孔的种是单个；圆角上的不动。
7. 再按一次：回执删掉的旧符号线个数等于上次新加的组数，结果与上次相同、没有重复。
8. 一排 5 个以上等距孔的视图按「孔位尺寸」：水平方向「基准→第一个孔」与「(N-1) x 间距 =总长」两个尺寸，竖直一个基准尺寸；
   孔上有中心符号线时水平尺寸连在中心线上（附着类型 24）；全部是线性尺寸。
9. 多种孔并排的视图按「孔位尺寸」：同种链式、不同种从基准起，同一段中心线间距只出现一次；孔标注、外形尺寸不动。
10. 再按一次（含视图里有手工按中心线标的旧尺寸，以及先按「中心符号线」造成的悬空尺寸）：旧的与悬空的全删、结果与上次相同、没有重复。
11. 含腰型孔（异形孔向导直槽口或草图切出）的视图按「孔标注」：每种腰型孔一个孔标注，挂在上端圆弧，规格完整；再按一次不重复。
12. 同一视图按「中心符号线」：每个腰型孔两端各有中心符号线，同种端头在一组线性里、连接线连起两端；开口槽口端头不动。
13. 同一视图按「孔位尺寸」：每个腰型孔只在上端圆心有水平、竖直位置尺寸；再按一次不重复。
14. （1.7.0）PowerSW 页是一行工具条（浮动 / 占位文字 / 类 / 取消）加「孔」控制面板（五个按钮一行、两个开关一行），没有表格；
    点「孔标注」等按钮即执行，执行中按钮显示运行态，结果进控制台。
15. 类选择框只有「孔」，选中时显示孔面板。
16. 点「浮动」：整页浮成置顶圆角小窗，盖在 SolidWorks 上，按住工具条中间的占位文字可拖动；在小窗里点按钮、切 SolidWorks 视图都能用；
    再点「浮动」（或停靠区占位的「还原」）放回原位。
17. （1.6.0）含异形孔向导销钉孔的视图按「销钉符号」：每个销钉孔一个销钉符号，普通孔没有；再按一次「都已有销钉符号」。
18. 孔位尺寸 / 孔标注的文字压在别的孔的尺寸界线、尺寸线、中心符号线上时：按「孔位尺寸」数字沿尺寸线滑开、按「孔标注」标注换到孔的另一个角；回执带「避让挪开」。
19. 按「孔标注全流程」（不点视图）：当前图纸页全部视图依次做完四步，回执逐步列出；连按两次结果相同、没有重复。
20. （1.7.0）关掉「避障」再按「孔位尺寸」「孔标注」：文字原地不挪、回执没有「避让挪开」；重开宿主后开关仍是关，再打开恢复避让。
21. 打开「尺寸链」再按「孔位尺寸」（多种孔的视图）：每个方向一组 SolidWorks 尺寸链（坐标尺寸），竖直组 0 在最上一排孔、
    文字一列在零件左边 14 mm，水平组 0 在最左一列孔、文字一行在零件上方 14 mm，挤的地方自动折弯；没有「(N-1) x」；回执「尺寸链 2 组」；
    再按一次结果一样；关掉再按恢复原标法且坐标尺寸删净，再打开再按线性尺寸删净；全流程同样照开关走。
    （2026-10-03 已在 WTJYQ-01-08 底板 View2 通过：0 点在左边线 / 上边线，共 67 个，开 / 开 / 关 / 开来回切都删净重标。）
22. （1.8.0）含异形孔向导销钉孔的视图按「销孔标注」：每种销孔的孔标注孔径带「H7(+偏差/0)」（三位小数）；同种相邻销孔之间的尺寸带 ±0.02，
    已有的改、没有的新加，销孔与别的孔之间不加；回执列出几种 H7、几个 ±0.02、新加几个。
23. 与别的孔同段被去重的销孔间尺寸后面有「(仅销孔)」；尺寸链模式下不写。
24. 再按一次：新加 0 个，公差与后缀不变；先按「孔位尺寸」重标后再按，±0.02 全部回来。
25. 按「外轮廓」（尺寸链关）：外轮廓每个竖直 / 水平台阶一个从左 / 上直边量起的尺寸（含总长总宽），一站一层排在现有尺寸外面；开口槽两壁与槽底算台阶，封闭型腔不算，斜边圆弧不标。
26. 再按一次：先删掉上次的外轮廓尺寸再标，结果相同。
27. 打开「尺寸链」按「外轮廓」：台阶加进孔的那组坐标尺寸（同一个 0 点），已有同值的跳过；再按「新加 0 个」；没有孔的组时新建一组；按「孔位尺寸」重标会连这些站一起删。
28. 在「检查」面板按「未标尺寸」（不点视图）：标齐的图回执「都没有查出漏标」。
29. 删掉一个孔位尺寸、一个销孔间尺寸、总长再按：逐条列出缺的孔 / 销孔间尺寸 / 外轮廓边，并在 SolidWorks 里选中它们；图上没有任何注解被改。
30. （1.8.1）一页上有主视图、侧视图（或俯视图）和一个等轴测图，按「孔标注全流程」：轴测图回执「是轴测图，跳过」、图上没有新注解；
    主视图标过的高度 / 长度，侧视图不再标（回执「N 站别的视图已标跳过」），侧视图只标主视图看不到的方向（深度）；再按一次结果相同。
    尺寸链模式同样不重复。之后「未标尺寸」不报侧视图缺高度，也不查轴测图。
31. 在 1.8.0 标过的图（两个视图都标了高度）上单独按侧视图的「外轮廓」：侧视图里重复的高度被删掉不再加。
