## 取舍

### 定位

- **作用于用户正在用的 SolidWorks，把一次手工操作变成一下点击。** 只附着、不启动、不隐藏、不退出、不替用户保存；批量转换、离线处理文件归 HistoryMinerva。
  两者用 SolidWorks 的方式相反，所以独立成模块（神名 Strenua，页面叫 PowerSW）。
- **进程内 STA 线程、一次一条。** 快捷指令都作用在同一个选择集上，两条同时跑会互相清选择。模块内不定义 `[ComImport]` 类型（可卸载上下文不支持），
  Interop 装进默认上下文；没有 OLE 消息过滤器，靠限时重试。
- **孔按几何认，不按特征认。** 阵列、镜像、手工切、导入件里的孔都要认；切成两段的圆柱孔认不出是已知代价。

### 孔类（用户逐条定）

- 每种孔只标一次（种 = 组件 + 孔壁特征 + 孔径），SolidWorks 孔标注自带「N×」；孔标注放孔的左上方，按下划线右端对准。
- 中心符号线一律「线性 + 连接线」、一种一组，先删孔上的旧符号线再标；腰型孔两端各算一个孔。
- 孔位尺寸：左 / 上直边为基准；同种链式、不同种从基准；同种一方向 >4 个且等距用「(N-1) x 间距 =」；按中心线去重；删旧重标（含悬空的线性尺寸）。
  删旧时 SolidWorks 会把外层尺寸往里收一层，删完放回原处。
- **对称轴**（1.14.1，用户示范）：视图里的边和孔整个关于一根轴对称、且有孔不在轴上时，插对称轴（中心线，选一对对边 `InsertCenterLine2`）。
  加轴是出图类的单独全图指令「对称轴」（用户定）；孔位尺寸遇到对称视图也自己补上它要的那根，再以它为基准——
  那个方向不从直边标、直接标对称轴两侧孔的距离；**同种互标、不同种不互标照旧**（每种仍是链，只是去掉基准到第一个孔那段）。
  孔全在轴上的方向照旧从直边标（示范保留了「5」）；同种 = 同特征同孔径，镜像到另一侧的别的特征不算对称。尺寸链模式不管对称。
  1.14.2（用户定：理论上对称的视图就要加轴）：有要定位的圆弧圆心（两端不都与直线相切、不与孔同心）的对称视图也加轴，没有孔也加；轴上的圆心那个方向不标。判对称仍要求所有边都镜像对得上（0.05 mm）——模型本身偏了（用户那块：槽偏 0.25、槽深差 0.15）不加，用户认可是模型问题。
- **对面孔**（1.14.1）：SolidWorks 孔标注的「N x」把背面的同种孔也数进去，视图只看得到一面。背面同种孔与这一面位置一一相同 → 孔标注后缀写「(含对面)」；
  不同 → 回执提示，「投影视图」在两头孔不一样时左右（上下）都加。判法：孔沿视线碰不碰零件两端外表面定正反面（孔口平面会把打进窗口的底孔当通孔），
  同种按各段孔径（镜像出来的特征名不同、被窗口截短的深度不同），是否同一孔标注里的看「N x」是否为这一面孔数的两倍（两头各打一半连成通孔的也靠它认）。
  腰型孔只标上方那个圆（横腰型孔取左端是我定的）。
- 尺寸链模式 = SolidWorks 中文界面的**坐标尺寸**（不是「链尺寸」）：每方向一组，0 点是零件最左 / 最上直边，不分种、无阵列写法。
- 销钉符号只给异形孔向导的销钉孔补；销孔标注 H7 带偏差值、销孔间 ±0.02 已有的改没有的补，只在同种相邻销孔之间（我定：不分种会串出跨板尺寸）；
  被去重并掉的那段写后缀「(公差仅对销孔)」。
- 外轮廓每个台阶都标；同一零件的外轮廓尺寸一页只标一处，「标过」按**模型面**连通判、不按数值。
- **孔标注、孔位一页只标一处**（1.15.0，用户定：顶视图、底视图都在时同一孔会被标两遍）：同一页上视线平行、引用同一模型的别的视图里，
  已有孔标注的种不再标、已有位置尺寸（线性 / 坐标尺寸连孔边或穿过孔心的线）的孔不再标；销孔标注的 H7、±0.02 同样跟着跳。
  同一个孔按零件里的轴线认（顶视图、底视图图纸坐标对不上）。位置按种算：那个视图里这种孔有位置尺寸、且它看得见这个孔，就算标过
  （阵列标法「4 x 75 =300」只连首尾两个孔，真机模组立板）。先标先得、不删别的视图已有的（可能是手工标的），所以全流程按视图顺序、后面的跳过前面标过的；
  孔位尺寸删旧时连这些孔上的旧尺寸照删（重跑能把以前重复的收掉一份）。
- **沉孔在背面**（1.15.0，用户定）：柱形沉头孔（沉孔与底孔同一特征）的沉孔在这个视图背面时，孔标注优先留给这一页看得见沉孔的视图（视线相反、看得见这个孔）；
  没有那样的视图才标在这里，后缀写「(反面)」——孔标注最后一行就是沉孔那一行，后缀接在它后面；「(含对面)」同在时排在它后面。
  主视图按孔、窗口打分常选盲销孔那面，所以沉孔常在背面；不为此另加视图。
- 孔标注全流程 = 当前图纸页全部视图（跳过轴测图），每视图 销钉 → 中心符号线 → 孔位尺寸 → 外轮廓 → 孔标注 → 销孔标注，某步失败不中断。
- **孔位尺寸躲图纸禁区**（1.16.0，用户指出移动底板上视图的尺寸压修改栏、图号框）：避障开着时，按默认边（水平在上、竖直在左）估每个尺寸占的地方，
  压到标题栏、修改栏、图号框、图纸注解、别的视图或出了图框，而换到另一边（视图下方 / 右侧）压得更少，就整组换过去（一样多不换）；
  之后数字沿尺寸线滑开时也把这些禁区当整块障碍。尺寸链模式（坐标尺寸）不换边。

### 类与一键（1.16.0，用户定）

- 页面上的类：**一键、孔、基础、倒圆、要求、检查**（「出图」改名「基础」、「倒圆倒角」改名「倒圆」、「技术要求」改名「要求」；指令名不变，`strenua.drawing.*`、`strenua.fillet.*`、`strenua.tech.*` 照旧）。
- 每一类有自己的「一键」，只做这一类里有的工作：基础类「基础出图」= 新建工程图 → 投影视图 → 轴测图 → 排版 → 对称轴（不插技术要求、不标注）；
  孔类「孔标注全流程」；倒圆类「全图倒圆倒角」= 全图圆心 → 全图圆弧 → 全图倒角。
- 一键类只有「一键出图」（`strenua.onekey.drawing`）= 把其他类的一键都做一遍：基础出图 → 孔标注全流程 → 全图倒圆倒角，技术要求在基础出图的排版之前插
  （排版要按它实际占的地方排视图，与以前的顺序一样）。检查类只读、不在里面。原 `strenua.drawing.auto` 删掉。

### 基础类

- 每一步都是单独的指令（人手工、AI 经 MCP 都能逐步做），基础出图、一键出图只是按顺序调它们。
- 新建工程图把新图名字改成零件名（1.15.0，用户定；`SetTitle2`，只对没保存的新图有效），第一次保存时默认文件名就是它；一键出图也走这里。
- 主视图、投影视图、图幅比例是按 15 张手工图（2026-025 台面2机器）归纳的近似：14/15 图幅比例一致，后板 A2 是已知差异。新图不保存。
- **主视图建完核对朝向**（1.16.0）：零件可能改过标准视图（「更新标准视图」），这时「*前视」不再沿 +Z（真机滑动板实际沿 +X，板面跑到下投影视图）。
  按名字建完读回视线，不对就删掉，按读回的朝向推出该用哪个命名视图（六个命名视图之间的关系不随改动变）再建，逐个核对；都对不上留原来那个并在回执里说。
- 圆弧（1.14.2 由「圆角」改名，用户定：它事实上管孔以外所有的圆）：R1 不标（技术要求「未注圆角R1」）、同半径 3 个以上合标；**识别所有圆、减去认得出是孔的**，剩下的外凸整圆标 Ø——圆弧标注不替孔标注擦屁股。
- **圆心位置**（1.14.2，用户定，单独指令「圆心位置」「全图圆心」，一键出图里在全图圆弧之前）：基准同孔位尺寸（左 / 上直边）。圆弧两端都与直线相切不标；
  都不相切（含整圆）标两个；一端相切只标一个——切线与两个基准都不平行时标哪个都行（取水平），切线平行于某个基准时**不能**以那个基准标（切线水平只标水平尺寸、竖直只标竖直尺寸）。
  我补的：两端切的线平行（腰形端头）沿线方向仍不定，按一端相切；同圆心的几段弧（含同心不同半径）切线合起来算；与孔同心的、落在基准 / 对称轴上的方向、已有尺寸量到圆心的方向不标；
  只认与直线相切，与另一段弧相切的一端当不相切；不删旧尺寸（圆弧位置常是手标的）。
  **去重**（第二轮，用户定）：某个方向坐标相同的圆心只标一个，其余用**中心线**（SolidWorks 中心线注解，不是改线型的线）连上——与孔、已标的圆心对齐的一个都不标、连到最近那个；这一轮几个圆弧圆心对齐的标离尺寸近的那个（水平取最高、竖直取最左）。中心线注解插不上就退回视图草图里画一根中心线线型（点划线）的细线——真机上选两段圆弧 `InsertCenterLine2` 返回空（它只认两条边或一个圆柱面），所以圆弧之间实际都是这根线。
- 倒角：用户否了 SolidWorks 倒角尺寸的引线样式，用普通线性尺寸写「C5」；同尺寸 2 个合标「2 x C」；C1 不标（C0.5 等别的尺寸照标）；只认平面倒角（锥面倒角要剖视图，没做）。
  避障（1.15.0，用户指出没做）：近档（视图外 8 mm）压着别的标注就往外一档档让（14 / 20 / 26 mm）或沿尺寸线滑开，压不压连尺寸线、尺寸界线穿不穿别的字一起算；
  障碍除这个视图的线与注解外，还有同一页别的视图（外框整块）和它们的注解，以及标题栏、修改栏与图纸上的注解（整块；真机移动底板「3 x C2」整个落在修改栏格子里、没碰边线）。
  跨视图不重复也按合标算：别的视图「4 x C2」只连着一张倒角面，它管到的同尺寸倒角都算标过（以前另一个视图会再标出「3 x C2」）。

### 页面与开关

- 没有指令表：每条快捷指令是所在类面板上的一个按钮，每类面板只声明一行、折行交给 Aurora；结果只进控制台。
  模块要新界面能力就让 Aurora 出通用指令 / 组件（浮动 `aurora.ui.float`、`fill`），不加特例组件。
- 避障、尺寸链两个开关固定在窗口最下面、所有类共用一份存档（`options.json`，记住上次）；避障管所有往图上加东西的指令，孔类三条的障碍只看孔相关注解。
- **「要求」类（1.16.0 前叫「技术要求」）下面的开关不是避障、尺寸链，是「AI 填写技术要求」**（1.14.0，用户定）：最下面一格跟着类切换，避障、尺寸链的值照旧生效、只是在这一类下不显示。

### 技术要求

- 模板只取 z 级目录 `2026-025-实验室测绘\z-SW模板配置\09 设计库\注释库\通用技术要求`（路径写死，用户说明长期稳定；热处理那组不用）；文字离线从 `.sldnotestl` 里取、`InsertNote` 插原文，字体随图纸模板。
- **只放标题栏正上方或左侧**（用户硬性要求，所有入口都守）；换一份时原处优先；避障开时挪压着的视图（只往上 / 往左），关着直接放上方不挪。
- 默认模板（表格「设置」列）给一键出图用，初值「机加件-钢材」。
- **AI 填写技术要求**（1.14.0，用户定）：输入 = 图纸截图 + 候选模板标题 + 图纸基本信息 JSON，输出 = 以哪份为基础（或没有）；再在基础上**克制地增删**，别整段重写。
  落成：AI 只能交回「删第几条 / 在第几条后加一条」，已有条目原样保留、编号由模块重排；每份最多删 3、加 3（代码兜底，不靠模型自觉）；没有基础才由 AI 写全文（≤10 条）。
  经总线调 HistoryApollo 的 `apollo.chat.ask images=`（模块统一接口，不引用 Apollo 程序集），带图请求由 Apollo 走识图供应商（通义千问）。
  开关开着时模板表格点哪份都由 AI **重新选基础**（用户选的，不是以点的那份为基础），一键出图那一步也走 AI；这两处 AI 没成就退回原来那份模板，按钮本身没成直接失败。
- **标题栏里有的不写进技术要求**（1.16.0，用户定）：名称、图号、材料、表面处理、热处理、比例、重量、数量已在右下角标题栏（模板属性链接带出）。
  两问的提示词都写明；AI 新加的条目以这些栏目名加冒号开头的（「材料：45钢」）代码兜底不采用，「材料去应力退火」这类工艺要求照常。模板原有条目不动。

### 检查类

- 只读：不加、不删、不挪注解，只改选择（选中 = 高亮）。查出问题也回执成功；有问题时经总线弹 Aurora `aurora.ui.dialog kind=content`，不等人关窗。
- **未标尺寸**（1.16.0 重写，用户定：别依赖标注那一侧，独立查有没有东西没标）：不再按本模块怎么标去比对，而是**尺寸网**——
  图纸上竖直边的 X、水平边的 Y、孔心与圆弧圆心的坐标各是模型里的一个面，线性 / 坐标尺寸把两头的面连起来，同一模型的各视图合成一张网（别的视图标过也算）；
  不用尺寸也定了的另连上：圆弧一端与水平 / 竖直直边相切、腰型孔两端、阵列「N x」跨度里的、对称轴（中心线注解）两侧连通的一对面定了轴。
  每个方向连起来最多、且真有尺寸的那一块是主网，没连进去的就是漏了位置尺寸。大小另查：孔要孔标注或 Ø、R1 以上的圆弧要 R（同尺寸有一个标了就算，「N x」本来合着标）；
  斜边要连着尺寸（倒角 C、角度）或两端都定了。按技术要求，R1 圆角、C1 倒角不查。同一条线上的几段边只报一次、一起选中。
- **两位小数**（1.16.0，用户定单独一个按钮）：看图上显示的数字（不是尺寸值，「12.50」也算），小数点后两位及以上的选中并弹窗警告——一般不允许存在。
  孔标注的规格、公差不算（取与尺寸值对得上的那段字当主数字）。

## 真机才知道的

- 测试环境 SolidWorks 2025 SP5。`FaceInSurfaceSense` 为 true 表示面法向与曲面法向**相反**（与 API 文档字面相反，用最高 / 最低平面标定过）；换大版本后孔全认不出，先重做这组标定。
- 真机测试前必须确认用户没在用 SolidWorks（执行前一刻 `tasklist` 查），否则会附着到用户会话；用户开着的图未经同意不动。
- 连续建、关几十张图后 SolidWorks 私有内存能涨到 25 GB 把整机拖死（批量测试的副作用，单张出图不受影响）；批量测要分批、中途重启 SolidWorks。
- 探针以可卸载上下文装候选、走真实处理函数（本仓不留，用完即删）；卸载检测要等约 20 秒，旧探针目录里的 bin 会被 MSBuild 优先拾取。

## 已知缺口

- 1.15.0 在 a20 模组立板（加反向视图）、移动底板（顶 / 底视图）、滑动板（一键出图）上真机跑过：跨视图去重、沉孔留给看得见沉孔的视图、「(反面)」落在沉孔那一行、
  倒角避障与合标去重、新图改名都对。已有的孔标注不挪：旧图里沉孔标在背面视图的，重跑只补「(反面)」，要挪到正面视图得先删掉它。
