# HistoryStrenua 现行约定

本仓唯一的长期文档。这里只写**从代码和测试里看不出来的取舍**；做法以代码为准，SolidWorks API 的坑写在调用处注释里，
回执长什么样看各指令拼回执的那几行，每版做了什么看 `git log`。条目被推翻就直接改掉，不留历史。

## 架构

六层，依赖只朝下（`ArchitectureTests` 按源码查，违反就过不了 submit）：

| 层 | 放什么 | 不许 |
| --- | --- | --- |
| `Planning/` | 纯规则与数据：几何类型、各 `*Planner`、SVG 写法、错误类型、SolidWorks 枚举值（`SwConst`）。按主题分子文件夹，`Common/` 放两类以上共用的 | 碰 SolidWorks、碰指令上下文 |
| `SolidWorks/` | COM 外观：附着、Interop、重试、记账 | 懂业务 |
| `Runtime/` | 指令切面：`QuickCommand`、`QuickOutcome`、上下文、参数、执行器（排他、状态、耗时、先回话）、来源判断（`CommandOrigin`）、开关、笔记 | 知道具体哪条指令、读图 |
| `Sheet/` | 几类共用的读图与改图动作：`DrawingAccess`（活动工程图、当前页视图、等点选）、`HoleScan`、`DimensionEdit`、`CalloutEdit`、`Clearance`……；`Feedback/` 是 SVG、截图、本步反馈 | 声明指令 |
| `Commands/<类>/` | 指令执行体与登记项，文件夹名 = 指令名第二段（`strenua.hole.*` 在 `Commands/Hole/`） | 点名别的类（共用的下沉到 `Sheet/` 或 `Planning/`）；只有 `OneKey` 负责编排别的类 |
| `Page/` | 登记表 `QuickCommands.All`、页面描述、`strenua.quick.*`、页面协议与开关指令 | 写图 |

根目录只有模块入口与身份（合同脚本按根路径读）；`HistoryStrenuaModule` 只做装配。

切面只有一份：改图读图一律走 `QuickCommandRunner`（反馈由入口注入）；来源只问 `CommandOrigin`；回执只用 `QuickOutcome`（没动图用 `Nothing`）；用户能纠正的前置条件抛 `QuickCommandException`，参数错抛 `QuickArgumentException`；
活动工程图只问 `DrawingAccess.ActiveDrawing`；逐视图走 `ViewFlow.EachView`，多步走 `StepLog`；多处要用的枚举值进 `SwConst`，清选择与重绘用 `api.ClearSelection` / `api.Redraw`。
命名空间不跟文件夹走，全是 `HistoryStrenua`（搬家不改调用方）。不进登记表的只有不碰图或没有按钮的：`tech.apply`、`tech.default`、`prop.default`、`note.*`、`option.*`、`ui.*`，由各自的 `*Commands` 声明。

## 取舍

### 定位

- **作用于用户正在用的 SolidWorks，把一次手工操作变成一下点击。** 只附着、不启动、不隐藏、不退出、不替用户保存；批量转换、离线处理文件归 HistoryMinerva。
  两者用 SolidWorks 的方式相反，所以独立成模块（神名 Strenua，页面叫 PowerSW）。
- **建模、装配也归这里**（1.38.0，用户定：SolidWorks MCP 连旋转零部件都做不到，是玩具，以后不依赖它）。AI 从零做一台机器（2026-043）时缺的建模、摆位、干涉都补进 Strenua，同一个执行器、同一份回执。
  例外只有「新建零件」：新文件建完立即存盘（文件在才能被总装引用）；改已有零件、总装仍不替用户保存。
- **进程内 STA 线程、一次一条。** 快捷指令都作用在同一个选择集上，两条同时跑会互相清选择。模块内不定义 `[ComImport]` 类型（可卸载上下文不支持），
  Interop 装进默认上下文；没有 OLE 消息过滤器，靠限时重试。
- **孔按几何认，不按特征认。** 阵列、镜像、手工切、导入件里的孔都要认。
  切成两段半圆的整圆孔（导入件，1.25.0）：同心同半径、背对背的两段并成一个孔（`SplitHole`）。SolidWorks 孔标注从半圆进去只写 R，所以标直径尺寸，前缀写「N x Ø」，后缀写完全贯穿或深度，下一行写沉孔；通不通问临时孔标注（按零件总厚判会错，夹爪局部 22 厚、总厚 40）。这种直径尺寸不算孔标注，重跑会重复。

### 孔类（用户逐条定）

- 每种孔只标一次（种 = 组件 + 孔壁特征 + 孔径）；**数量对齐标注的组**（1.35.1，用户定）：「N x」= 这一组在这个视图的孔数，含对面是两倍。SolidWorks 对导入特征不写、对跨面特征多数，都按组改；一组被手工分成几个标注时不改，「未标尺寸」核对合计。导入件的沉头孔按几何补沉孔那一行（背面的看不到，不补）。1.18.0 起孔标注优先左下，左侧空间不足再向上找位，按下划线端点对准。
- 中心符号线一律「线性 + 连接线」、一种一组，先删孔上的旧符号线再标；腰型孔两端各算一个孔。
- 孔位尺寸：左 / 上直边为基准；同种链式、不同种从基准；同种一方向 >4 个且等距用「(N-1) x 间距 =」；按中心线去重；删旧重标（含悬空的线性尺寸）。
  删旧时 SolidWorks 会把外层尺寸往里收一层，删完放回原处。
- **对称轴**（1.14.1，用户示范）：视图里的边和孔整个关于一根轴对称、且有孔不在轴上时，插对称轴（中心线，选一对对边 `InsertCenterLine2`）。
  加轴是出图类的单独全图指令「对称轴」（用户定）；孔位尺寸遇到对称视图也自己补上它要的那根，再以它为基准——
  那个方向不从直边标、直接标对称轴两侧孔的距离；**同种互标、不同种不互标照旧**（每种仍是链，只是去掉基准到第一个孔那段）。
  孔全在轴上的方向照旧从直边标（示范保留了「5」）；同种 = 同特征同孔径，镜像到另一侧的别的特征不算对称。尺寸链模式不管对称。
  1.14.2（用户定：理论上对称的视图就要加轴）：有要定位的圆弧圆心（两端不都与直线相切、不与孔同心）的对称视图也加轴，没有孔也加；轴上的圆心那个方向不标。判对称仍要求所有边都镜像对得上（0.05 mm）——模型本身偏了（用户那块：槽偏 0.25、槽深差 0.15）不加，用户认可是模型问题。
- **对面孔**（1.14.1）：SolidWorks 孔标注的「N x」把背面的同种孔也数进去，视图只看得到一面。背面同种孔与这一面位置一一相同 → 孔标注后缀写「(含对面)」；
  不同 → 回执提示，「投影视图」在两头孔不一样时左右（上下）都加。判法：孔沿视线碰不碰零件两端外表面定正反面（孔口平面会把打进窗口的底孔当通孔），
  同种按各段孔径（镜像出来的特征名不同、被窗口截短的深度不同），是否同一孔标注里的看「N x」是否为这一面孔数的两倍（两头各打一半连成通孔的也靠它认）。
  腰型孔只标上方那个圆（横腰型孔取左端是我定的）。
- 尺寸链模式 = SolidWorks 中文界面的**坐标尺寸**（不是「链尺寸」）：每方向一组，0 点是零件最左 / 最上直边，不分种、无阵列写法。
- 销钉符号只给异形孔向导的销钉孔补；销孔标注 H7 带偏差值、销孔间 ±0.02 已有的改没有的补，只在同种相邻销孔之间（我定：不分种会串出跨板尺寸）；
  被去重并掉的那段写后缀「(公差仅对销孔)」。
- **方形槽**（1.17.0，用户定，样图 WTJYQ-04-02 右防护板）：标封闭方形槽（矩形窗口）的位置。认法：不在外轮廓上的两竖两横直边围成矩形、四角缺的一样多（直角或同样大的圆角）；
  开口槽归外轮廓。图上分不出槽与凸台，问 SolidWorks 贴着边、正对图纸的面往不往矩形里延伸（只问点在不在面上，不靠法向正负）。
  标法（我定）：基准同孔位尺寸；每个槽每个方向一层，「基准 → 近边」「近边 → 远边」并排（位置连带长宽一起标），排在现有尺寸最外层之外；尺寸链模式四条边并进孔的那组。不跨视图去重。
- **孔标注、孔位一页只标一处**（1.15.0，用户定：顶视图、底视图都在时同一孔会被标两遍）：同一页上视线平行、引用同一模型的别的视图里，
  已有孔标注的种不再标、已有位置尺寸（线性 / 坐标尺寸连孔边或穿过孔心的线）的孔不再标；销孔标注的 H7、±0.02 同样跟着跳。
  同一个孔按零件里的轴线认（顶视图、底视图图纸坐标对不上）。位置按种算：那个视图里这种孔有位置尺寸、且它看得见这个孔，就算标过
  （阵列标法「4 x 75 =300」只连首尾两个孔，真机模组立板）。先标先得、不删别的视图已有的（可能是手工标的），所以全流程按视图顺序、后面的跳过前面标过的；
  孔位尺寸删旧时连这些孔上的旧尺寸照删（重跑能把以前重复的收掉一份）。
- **沉孔在背面**（1.15.0，用户定）：柱形沉头孔（沉孔与底孔同一特征）的沉孔在这个视图背面时，孔标注优先留给这一页看得见沉孔的视图（视线相反、看得见这个孔）；
  没有那样的视图才标在这里，后缀写「(反面)」——孔标注最后一行就是沉孔那一行，后缀接在它后面；「(含对面)」同在时排在它后面。
  主视图按孔、窗口打分常选盲销孔那面，所以沉孔常在背面；不为此另加视图。
- 孔标注全流程 = 当前图纸页全部视图（跳过轴测图），每视图 销钉 → 中心符号线 → 孔位尺寸 → 方形槽 → 孔标注 → 销孔标注，某步失败不中断。
  外轮廓 1.17.0 起不在这里（用户定：移出孔类，归基础类；1.23.0 起在一键类）。
- **孔位尺寸躲图纸禁区**（1.16.0，用户指出移动底板上视图的尺寸压修改栏、图号框）：避障开着时，按默认边（水平在上、竖直在左）估每个尺寸占的地方，
  压到标题栏、修改栏、图号框、图纸注解或出了图框（1.32.2 起不看别的视图，视图由最后的排版让开），而换到另一边（视图下方 / 右侧）压得更少，就整组换过去（一样多不换）；
  之后数字沿尺寸线滑开时也把这些禁区当整块障碍。尺寸链模式（坐标尺寸）不换边。
- **位置尺寸两侧都放**（1.23.0，用户定：「标注可以放视图左右上下两侧而不是一侧，均衡的话直接测引线长度，优先选引线短的那一侧」）：
  孔位尺寸、方形槽、圆心位置不再整组挤一侧——水平尺寸上方或下方、竖直尺寸左侧或右侧，**逐组挑**（孔位按每种孔、方形槽按每个槽、圆心按每个圆心）：
  先比压禁区几处（避障开着时才有禁区），一样多量尺寸界线总长（孔心 / 槽边引到尺寸线），选短的一侧；一样长放已排层数少的一侧（1.32.3，用户定），层数也一样放上方 / 左侧。
  两侧各自由里到外排层，一侧层多了再往这侧放的界线就长，所以不另做数量均衡（`DimensionSides`）。放下方 / 右侧时每站连最下 / 最右的那个孔。
  尺寸链模式整组（每方向一组坐标尺寸）挑一侧。方形槽、圆心的另一侧第一层在那一侧现有尺寸最外的再往外一层（`Outline.Sides`）。
  销孔间尺寸本来就贴着两孔放（不在视图外），上下两种放法引线总长相同，不动；普通模式下销孔间尺寸多半是已有孔位尺寸改的，跟着孔位尺寸两侧放。

### 类与一键（1.16.0，用户定）

- **1.23.0（用户定，页数少）**：「基础」类拆掉——新建工程图、投影视图、轴测图、排版进「视图」类（第二行，视图列表 / 挪视图在第一行），
  基础出图、整理标注、对称轴、全图外轮廓、外轮廓并进「一键」类（第三行）。现在页面上的类：**一键、孔、倒圆、视图、标注、要求、检查**。
  只动页面（`QuickCommand.Page`），指令名不变（`strenua.drawing.*` 照旧），MCP 调用不受影响。下面 1.16.0 的说法里「基础类」即这些指令。
- 每一类有自己的「一键」，只做这一类里有的工作：基础类「基础出图」= 新建工程图 → 投影视图 → 轴测图 → 排版 → 对称轴（不插技术要求、不标注）；
  孔类「孔标注全流程」；倒圆类「全图倒圆倒角」= 全图圆心 → 全图圆弧 → 全图倒角。
- 一键类（1.17.0，用户定）：「一键出钣金」「一键出框架」「一键出加工件」（`strenua.onekey.sheetmetal / frame / machined`）。1.28.0（用户定）删掉总的「一键出图」：AI 总爱用它，粒度只到这一级，类别由调用方判断。1.19.0 起三条结束前都会执行「整理标注」（`strenua.drawing.finish`），按整页真实文字、引线、尺寸线和图框复核，未解冲突使一键结果失败。
  钣金、框架只在一键类里，不单成类。三条都先做基础出图，技术要求在排版之前插（排版要按它实际占的地方排视图）——就是同一条技术要求
  （用户定：技术要求已统一交给 AI 选，「AI 填写技术要求」开着走 AI、关着插默认那份，三类不另设默认）。之后按类别：
  - 钣金：孔标注全流程（含方形槽）→ 全图外轮廓。不标圆弧倒角。
  - 框架：全图外轮廓（离别的站不到一个型材宽的不标，我定：每根型材的另一条边、端面 T 型槽口的小台阶都由型材规格定了）→ 轴测图最右上角引一条「采用 xx 铝型材」（样图 WTJYQ-04-01）。
    xx 取焊件结构构件的型材文件名（「20x20」写成「2020」），没有焊件按每个实体包围盒的截面猜，都没有写「采用铝型材」。不标孔。
  - 加工件（其他情况）：孔标注全流程 → 全图外轮廓 → 全图倒圆倒角。
- **修正要点**（1.28.0，用户定）：一键只出初稿，三条的回执末尾都带本类的修正要点（`OneKey/OneKeyFix.cs`），调用方必须照着修完。
- **检查类弹窗**（1.29.0，用户定）：只有手动点才弹窗，AI（来源含 MCP）调用只看回执。
- **尺寸链**（1.30.0，用户定，`strenua.check.chain`）：不从基准开始的尺寸必须在尺寸链上。基准是最左、最上的直边，贯穿视图的对称轴也算；从基准沿「同一行（图纸 0.5 mm 内）、首尾相接」走得到的才算在链上。不在的分三种报：换了行、整条链接不到基准、孤立（给出从基准标的值）。坐标尺寸、C 倒角、带公差的不查。「整理标注」换行时同一条链整条一起走，只有沿线滑可以单独动。
- **重标尺寸**（1.29.0，用户定，`strenua.check.redundant`）：能由别的尺寸算出来的线性、坐标尺寸都报，跨视图也算。按方向建图（面是点、尺寸是边），腰型孔、对称轴、未注倒角、阵列等距孔、没标 R 的相切先并点；R 连圆心与切线、C 连斜边两头也是边（用户定，如 13 = 18 − R5），一组全是 R、C 不报（几处圆角恰好等高等大，各管各的）；两头并成一点的尺寸单独报，其余找桥，非桥边的连通块是一组，多余数 = 边数 − 点数 + 1。最大生成树（公差 > 阵列 > 总尺寸 > R、C > 整数）之外的是建议删的并带算式，删哪个由 AI 权衡。不判孔径、角度、斜向距离。相切按圆判：圆心到直线的距离等于半径、切点在线段上或差不到一个半径就算，不看弧端点接没接上（真机夹爪2 的 R5 只画到一半）；圆心位置、未标尺寸共用这个判法。
- **笔记区**（1.28.0，用户定）：`strenua.note.write area= text= [replace=]` 记细节调整与反思，`strenua.note.read` 读；经 MCP 的每条回执（含 `quick.last`、「还在执行」）最上面带通用区 + 本类区，人点按钮不带。存模块数据目录 `notes.json`，不碰 SolidWorks。
  1.38.0（用户定：笔记只记指令本身很少的注意点，不记项目内容）：一条不超过 100 字、每区不超过 6 条，超了直接拒；某个零件、某张图的事写进项目自己的文档。
- 外轮廓放在孔标注全流程之后、不并进基础出图（我定）：尺寸链模式下外轮廓并进孔的那组坐标尺寸，孔位尺寸重标会连 0 点删整组。检查类只读、不在一键里。

### 公差类（1.36.0，用户定：先有标注能力，公差值准不准这版不管；同样不上页面，只给 AI）

### 第二轮真机后的修复（1.27.0）

- **孔标注选位**（`strenua.hole.place`，一键流程最后一步，框架除外）。**孔标注只排这一次（1.35.1，用户定）**：之前的避障、整理标注、排版都不看也不挪孔标注；到这一步视图和别的标注都定了，障碍是整页所有视图的所有标注，还没排到的孔标注不算障碍。单独按「孔标注」「孔标注全流程」时（避障开着）也在最后选一次。整页标完后读一遍，同种的孔（最多 12 个）四周 ±40 mm 每 4 mm 一格折点、字朝左右都算分：字压东西最重，其次引线穿字、穿别的引线、穿尺寸，再次引线长；板内空白与视图外同等对待。比现在好 5 分以上才动，所以重复跑不乱动。换挂是先加新的、成了再删旧的，SolidWorks 不接受就留在原处。
- 选位算在本地，每个标注最多写一次（真机逐个候选试挪太慢）。
- `dim.hole` 加 `side=left|right` 指定字朝向；字的中点要过孔心，否则 SolidWorks 把引线接到另一头，回执会说。新加的孔标注自动带「(反面)」「(含对面)」。
- `dim.list` 的中心符号线多一列 `holes`（图纸 SVG 孔编号）。
- 「未标尺寸」少报三类：只连一条边量自身跨度的尺寸定了这条边两头；顺着看的未注倒角短直边；圆心半径都定了的圆弧，其端点在别的视图里那条直边。最后一条不并进尺寸网，否则端点碰巧落在已标的边上时，没标的圆心也会算标过。

### 建模、装配、螺纹孔（1.38.0，用户定：SolidWorks MCP 弃用，建模装配并进来；孔标注加专门指令并修乱码；不上页面，只给 AI）

- 建模类 `strenua.model.new / sketch / extrude / plane / delete / info`：一张草图一条指令画完（rect / box / circle / circles / poly / slot，分号隔开），再拉伸或切除；切除朝空处建不出特征时自动换向，体积没变按失败报。
  标准三面按特征树前三个基准面认、不认名字（中英文 SolidWorks 都行），回执写清草图坐标与零件坐标的对应（上视 y = −Z、右视 x = −Z）；表面草图从草图变换读出轴向与原点写进回执。
  `model.info` 给包围盒、体积、特征树和全部孔（按几何认，孔心取轴线上离原点最近的点），供摆位和接口孔核对。
- 装配类 `strenua.asm.list / insert / move / delete / interference`：摆位写「零件原点落点 + 零件三根轴各朝总装哪根轴」（`axes=X,-Z,Y`，必须右手系），直接写变换并默认固定、不加配合（我定：AI 按设计坐标摆，比配合好核对）；
  固定着的零部件要先解除固定再改变换。干涉检查不算贴合面，干涉区某向厚度不到 0.1 mm 的也算贴合、只计数（真机：型材顶面压模组底面，导入模型差 0.03 mm，SolidWorks 报 516 mm³）。
- **符号码**：凡是写进尺寸、孔标注、技术要求的文字都把 Ø ⌀ ↧ ⌴ ⌵ ± ° 换成 `<MOD-DIAM>`、`<HOLE-DEPTH>` 等（`SwText`）。真机（2026-043 货叉托板）：前缀里直接写 Unicode「↧」「Ø」，SolidWorks 用正文字体画成乱码、和数字挤在一起。
- **螺纹孔** `strenua.dim.thread`（模型里螺纹孔画成底孔时用，我定写法）：隐藏尺寸值，盲螺纹两行「4 x M6↧12」「孔↧15」、螺纹贯穿一行「4 x M6 贯穿」，底孔直径由规格定不写；底孔深与孔数默认读原标注，规格与图上底孔对不上只提醒。

- 真机（2026-11-03，2026-043 立式货架取货机）：建模新建 → 草图 → 拉伸 → 贯穿切除 4 孔加腰型槽 → 表面草图盲孔 → 偏置面 → 删特征 → 信息读回全对；装配插入带旋转、列表、摆位、干涉（重叠 10 mm 报 231 cm³）对；
