# HistoryStrenua 模块 API

模块版本：**1.3.0**；宿主基线：**HistoryVulcan 5.1.2**。

本文件是**总线面**合同：模块消费方的权威合同，随发布候选进包（`docs/模块API.md`）。
模块内部类型见 `b-Office/current/技术合同.md`；AI 面（MCP 工具）由 MCP 服务封装，本文件不重复。

## 这个模块提供什么

PowerSW：作用于用户**正在用**的 SolidWorks 的快捷指令。每条快捷指令是 Aurora 页面上的一个按钮，
也是一条可以在控制台、脚本或别的模块里经总线调用的指令。

指令域：`strenua`。模块 `ui=true`，`mcpExposure=readonly`（只有 `strenua.quick.list` 投影到 MCP）。

**共同前提**：SolidWorks 必须已经在运行。本模块只附着，不启动、不隐藏、不退出它；
一次只执行一条快捷指令，第二条直接失败回执「还在执行」。

## 指令

### strenua.hole.callout

| 格 | 内容 |
| --- | --- |
| 能做什么 | 在当前工程图里取一个视图，视图里看得见、正对图纸的孔**每种标一次**（数量由 SolidWorks 的「N×」带出）；已有孔标注的种跳过 |
| 谁会用 | PowerSW 页面「孔标注」按钮；控制台直接敲 |
| 怎么调 | `strenua.hole.callout`（无参数）。调用前若 SolidWorks 里已选中视图（或视图里的任何对象）就用它，否则等用户点选，最多 60 秒 |
| `Data` 的确切类型 | 无（`null`）。结论只在 `Message`：`视图「X」：H 个孔（含 S 个腰型孔）共 T 种，新加 N 个孔标注，M 种已有标注跳过，K 个 SolidWorks 没有接受。` |
| 失败与边界 | 失败：SolidWorks 未运行 / 未注册；没有打开文档或活动文档不是工程图；60 秒内没点选视图；视图不引用模型；已被取消；确有要加的孔但一个都没加上。成功但无改动：视图里没有正对图纸的孔、或孔都已有标注 |

判孔规则：整圈圆边 + 旁边一张内凹且同半径的圆柱面 + 轴线正对图纸。异形孔向导的各类孔与手工切孔都算；
开口槽口的端部半圆、凸台外圆、侧视投影不算。同心的圆边（沉头与底孔、通孔上下口）算一个孔。
一种 = 同一组件、同一特征、同一孔径；标在这一种里最靠左上的孔上。

**腰型孔（1.3.0）**：两端恰好半圈、同样贴着内凹同半径圆柱面的两条圆弧，互相背对着鼓、同特征同半径，配成一个腰型孔
（异形孔向导的直槽口与草图切出来的都算；回执里「含 S 个腰型孔」，一个腰型孔算一个孔）。同一特征里长度不同的腰型孔是两种。
孔标注选上方那一端的圆弧，由 SolidWorks 一次写全规格；已有标注挂在任一端都算标过。配不上的半圆（开口槽口）仍不算孔。

执行中会经 `CommandContext.Progress` 逐步报告（等待点选、识别孔、加标注），消费方不必从结论里复述过程。

### strenua.hole.centermark（1.1.0）

| 格 | 内容 |
| --- | --- |
| 能做什么 | 在当前工程图里取一个视图，视图里看得见、正对图纸的孔**全部重标中心符号线**：先删标着这些孔的旧中心符号线，再每种孔一组「线性中心符号线 + 连接线」，只有一个孔的种用单个 |
| 谁会用 | PowerSW 页面「中心符号线」按钮；控制台直接敲 |
| 怎么调 | `strenua.hole.centermark`（无参数）。取视图方式与 `strenua.hole.callout` 相同 |
| `Data` 的确切类型 | 无（`null`）。结论只在 `Message`：`视图「X」：H 个孔（含 S 个腰型孔）共 T 种，删掉旧中心符号线 D 个，新加线性带连接线 L 组、单个 S 个，K 个孔 SolidWorks 没有接受。` |
| 失败与边界 | 失败：与孔标注相同的前置条件；旧中心符号线删三遍仍删不掉（此时不重标）；一个都没加上。成功但无改动：视图里没有正对图纸的孔 |

认孔、分种规则与孔标注相同。**腰型孔两端的圆弧各当一个孔标一次**，同种的端头在同一组线性中心符号线里，一个腰型孔两端之间由连接线连起。
不在孔上的中心符号线（圆角、开口槽口）不动；标在腰型孔端头上的旧符号线算在孔上，会删掉重标。

### strenua.hole.position（1.2.0）

| 格 | 内容 |
| --- | --- |
| 能做什么 | 在当前工程图里取一个视图，视图里看得见、正对图纸的孔**全部重标位置尺寸**：以零件最左的竖直直边、最上的水平直边为基准；先删连着这些孔的旧位置尺寸，再重标 |
| 谁会用 | PowerSW 页面「孔位尺寸」按钮；控制台直接敲 |
| 怎么调 | `strenua.hole.position`（无参数）。取视图方式与 `strenua.hole.callout` 相同 |
| `Data` 的确切类型 | 无（`null`）。结论只在 `Message`：`视图「X」：H 个孔（含 S 个腰型孔）共 T 种，删掉旧位置尺寸 D 个，新加 N 个（阵列标法 P 个；连在中心线上 C 个，其余孔上没有中心符号线、连在孔边上），K 个 SolidWorks 没有接受。` |
| 失败与边界 | 失败：与孔标注相同的前置条件；视图里找不到竖直或水平的直边做基准；旧位置尺寸删三遍仍删不掉（此时不重标）；要加的一个都没加上。成功但无改动：视图里没有正对图纸的孔 |

怎么标：

- 每个方向（水平量 X、竖直量 Y）、每种孔单独标：同种孔第一条中心线从基准标，其余接着前一条标；不同种孔一律从基准起。
- 同种孔一个方向超过 4 条中心线且等距（差 ≤ 0.01 mm）用阵列标法：基准到第一个孔一个尺寸，第一个到最后一个一个尺寸，
  文字前缀「(N-1) x 间距 =」，后面是 SolidWorks 自己的总长，显示成「10 x 60 =600」。不等距退回逐个接着标。
- **按中心线标、不按孔标**：同一段「中心线 → 中心线」（含基准到中心线）全视图只标一次，并排的几种孔不出重复尺寸。
- 水平尺寸的孔那一头连在孔上的中心符号线（竖线）上；孔上没有中心符号线就连孔边。竖直尺寸一律连孔边
  （SolidWorks 选中心符号线加竖直尺寸只会拿竖线、建成角度尺寸）。连孔边时 SolidWorks 量到圆心，数值相同。
- 水平尺寸放在上侧基准之上、竖直尺寸放在左侧基准之左；一种孔一层，第一层离基准 8 mm、层距 6 mm，跨度短的在里。
  **不避让相邻视图**：视图挨得近时尺寸会压到旁边的视图上，需要手工挪视图或尺寸。
- 旧位置尺寸 = 连着这些孔的孔边、或连着穿过孔心的中心线（中心符号线、中心线）的线性尺寸。孔标注、直径尺寸、
  外形尺寸不动；角度、坐标尺寸不动。旋转过的视图不认连在中心线上的旧尺寸（只认连在孔边上的）。
- 腰型孔（1.3.0）只标**上方那一端**圆弧的圆心（两端一样高取左端）；其余规格由孔标注一次写全，不另标长度。
  连在任一端上的旧位置尺寸都算旧的，会删掉重标。
- 先跑「中心符号线」再跑「孔位尺寸」：反过来的话，重标中心符号线会删掉尺寸连着的旧符号线，尺寸就悬空了。

### strenua.quick.cancel

| 格 | 内容 |
| --- | --- |
| 能做什么 | 取消正在执行的快捷指令，包括正在等用户点视图的那一条 |
| 谁会用 | PowerSW 页面「取消」按钮 |
| 怎么调 | `strenua.quick.cancel` |
| `Data` 的确切类型 | 无 |
| 失败与边界 | 不失败：没有在跑的指令时也回成功，只说明没有可取消的 |

被取消的那条指令本身回执失败「已取消」。已经加上的标注不回滚。

### strenua.quick.list（只读）

| 格 | 内容 |
| --- | --- |
| 能做什么 | 列出全部快捷指令、当前状态与上次结果 |
| 谁会用 | AI（MCP）、控制台 |
| 怎么调 | `strenua.quick.list` |
| `Data` 的确切类型 | `IReadOnlyList<IReadOnlyDictionary<string,string>>`，每行键：`id`、`title`、`usage`、`state`、`result`、`time`（`HH:mm:ss`，未执行过为空） |
| 失败与边界 | 不失败 |

`state` 取值：`就绪`、`附着 SolidWorks`、`等待点选视图`、`识别孔`、`加标注`、`删旧符号线`、`加中心符号线`、`删旧尺寸`、`加尺寸`、`完成`、`失败`、`已取消`。

## 界面内部协议（不要跨模块调）

`strenua.ui.describe` / `strenua.ui.actions` / `strenua.ui.data` 是 Aurora 页面协议，声明了 `HiddenReason`。
页面 owner 与场景 id 为 `HistoryStrenua`；页面 id `powersw`，状态表节点 `quick-commands`。
